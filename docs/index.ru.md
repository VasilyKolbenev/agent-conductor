## Попробовать Studio

- **Две свои задачи на Windows.** Запишите, как проверяли завершённую задачу. Во второй попросите Колосса восстановить этот порядок, откройте источник и поправьте предложенный план в чате. Скачайте ZIP для Windows, распакуйте его и откройте `START.cmd`. Этот сценарий работает офлайн. [Скачать Arachnid Studio](https://github.com/VasilyKolbenev/agent-conductor/releases/tag/v0.1.0-pilot.3) · [Инструкция](https://github.com/VasilyKolbenev/agent-conductor/releases/download/v0.1.0-pilot.3/START-HERE.txt).
- **Знакомство на Windows, Linux или macOS.** Установите wheel из релиза и выполните `conduct demo`. Откроется локальная учебная задача с записанной попыткой и решением, которое ждёт оператора. Подписка для демо не нужна. [Команды установки](../README.ru.md) · [Содержание демо](../demo/README.md).
- **Своя команда харнессов.** Подключите утилиты, назначьте роли, проверьте лимиты и разрешите запуск в Studio. Полный цикл Codex и Grok по личным подпискам проверен на Windows. [Первый рабочий проект](first-run-v1.md).
