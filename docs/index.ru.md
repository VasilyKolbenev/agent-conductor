## Попробовать Studio

- **Учебный пример и две свои задачи на Windows.** Распакуйте ZIP и откройте `START.cmd`, чтобы посмотреть завершённый пример Codex + Grok. Команда `.\START.cmd new` открывает две ваши задачи. Запишите порядок проверки первой задачи, во второй попросите Колосса найти источник и измените план в чате. Оба сценария работают офлайн. [Скачать Arachnid Studio](https://github.com/VasilyKolbenev/agent-conductor/releases/tag/v0.1.2) · [Инструкция по установке](https://github.com/VasilyKolbenev/agent-conductor/releases/download/v0.1.2/START-HERE.txt).
- **Знакомство на Windows, Linux или macOS.** Установите wheel из релиза и выполните `conduct demo`. Откроется локальная учебная задача с записанной попыткой и решением, которое ждёт оператора. Подписка для демо не нужна. [Команды установки](../README.ru.md) · [Содержание демо](../demo/README.md).
- **Подключение своих инструментов.** Выберите ручную передачу, совместимый текстовый мост или встроенный адаптер с ролями в цикле. Полный цикл Codex и Grok по личным подпискам проверен на Windows. [Подключение в картинках](../README.ru.md#подключить-свой-харнесс) · [Первый рабочий проект](first-run-v1.md).
