## Проверка

В трёх запусках временного проекта запрошен предпросмотр через HTTP установленного сервера.
Ответ сверялся с узлами и digest замороженного графа. В Chromium открыт экран Studio для
каждого запуска и нажата кнопка просмотра. Отдельно отрисована установленная карточка
Desk на ответе того же API. Во всех вариантах проверены видимость, число и адресат пометок.

| План | Ответ API | Studio и карточка Desk |
| --- | --- | --- |
| Точный G6 с diagnose и result-gate | Только diagnose | Одна пометка у diagnose |
| G6 с соседним обычным review того же Grok | Только diagnose | У второго review пометки нет |
| Тот же G6 без признака | Поле отсутствует | Пометок нет |

Сервер работал в режиме просмотра на loopback с пустым тестовым профилем, неисполняемой
заглушкой Grok и запретом запуска процессов и внешних соединений. Счётчик запрещённых
попыток равен нулю. В каждом журнале остались определение графа и входной артефакт.
Разрешений и действий 0. После остановки ownership вернул `closed`.
