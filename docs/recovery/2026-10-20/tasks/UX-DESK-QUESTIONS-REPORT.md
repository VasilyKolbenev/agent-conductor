# Вопросы о новой задаче

Итог: из чистого wheel `ae343a3` коллега описал задачу одной фразой, ответил только
про отсутствующий источник файлов, изменил цель и назначение через те же поля,
затем дошёл до настоящего предпросмотра без разрешения на выполнение. Проверены RU
при 375 px и EN при 1280 px, светлая и тёмная темы.

## Что изменилось на экране

На исходной сборке пустой первый экран спрашивал про Git до постановки задачи.
Под пустой целью дважды появлялось требование дать заголовок, несмотря на то что
заголовок выводится из первой фразы. Красный свидетель подтвердил преждевременный
выбор источника в Chromium. Теперь сначала виден вопрос про результат, пример
и переход к обычным полям. Доступная кнопка **Продолжить** выделена акцентом
палитры. Недоступная кнопка имеет пунктирную границу. Статус сохранения короткий;
условия восстановления раскрываются под ним. Ошибки сохранения остаются видимыми.

Мастер показывает уже известный коммит или спрашивает, откуда взять файлы.
Ранее заданный ответ можно изменить рядом с ним. Критерий готовности и материалы
попадают в ту же задачу. Команда показывает фактическую причину выбора цикла, кто
может исполнить действие в рабочей папке, кто читает материалы для диагноза,
кто проверяет фактический результат. Там, где модель назначений выбрала отдельного
проверяющего, экран это объясняет. Ввод неполного указания остаётся на экране, пока
коллега пишет ответ. Все эти действия используют имеющуюся модель черновика.
