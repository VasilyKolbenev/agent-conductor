# Что проверено перед массовой альфой

Итог: локально проверено на Windows | код подключения `1b06b7f` | внешняя приёмка открыта.

## Что получает оператор

- **Две задачи.** Исправлена запись и сверка квитанций в глубокой папке Windows. На чистых
  установках с кириллицей источник, порядок проверок и обе задачи открылись после перезапуска.
  При прерванной публикации сохранилась папка проекта, созданная другим процессом.
- **Свой Codex или Grok.** Карточка активного проекта показывает пригодность роли, режим входа
  и сведения о квоте из кеша с источником. Команда для PowerShell использует переменные
  установленной Studio и выбранного проекта. Подготовить проверенный CLI, остановить сервер
  и завершить официальный вход должен владелец. Для запуска задачи нужно отдельное разрешение.
- **Колосс.** Сводка «Пока меня не было» читает состояние и решения запуска. В ней можно
  открыть изменения двух файлов, нативный протокол трёх unittest и отдельный вердикт Codex
  одной попытки. Для знакомства доступны архив и офлайн-пилот.
- **Kimi.** Переносимая опись проверяет три файла исходного комплекта. Для коллеги проверен
  отдельный источник Bash из Git for Windows 2.56.1 с хешем издателя. На испытанной
  машине Windows остановила сам CLI до открытия сессии. Роль на подписке ещё предстоит проверить.
  [Отчёт по комплекту](KIMI-INSTALL-MANIFEST-REPORT.md).

Мутанты пустой карточки, потери read-only и устаревшего состояния пойманы. Для мастера
пойманы пропуск валидации установки, пустая обработка входа и отключение проверки доступа.
Чужие файлы в других рабочих копиях сохранены. Независимое ревью исправило путь команды
и проверку прав файла входа. Модели и живые циклы в этой работе не запускались.

На установленном `305003d8` в чистом профиле дважды выполнен путь от активного
проекта до штатной остановки Ctrl+C и состояния `closed`. Каждое открытие прошло
203 HTTP-проверки; непустой журнал сохранил свой SHA-256. Офлайн-пилот двух задач
прошёл с кириллицей, пробелами и тремя правками плана. На ширинах 375 и 1440 px
установленная Studio открыла материалы принятой попытки без записи и внешних запросов.
Четыре сценария первого подключения прошли с чистого проекта. Ручной обмен с утилитой
Claude сохранил задачу, учебный ответ и подпись «Ответ записал оператор».
Полный core этой промежуточной версии выявил ошибки формата словаря и размещения правил
провайдеров в общем коде. Её wheel не выбран для выдачи.

Проверены код карточек, фактические изменения выбранной попытки и работа команд из

## Что показала повторная установка

На `8e6eec3a` двухзадачный ZIP прошёл путь через штатный START.cmd. Активная Studio
также приняла ответ локального совместимого моста и сохранила отдельно ответ оператора.
В обоих сценариях использовался установленный пакет. Модели не вызывались.

В отдельном новом venv на том же компьютере Windows заблокировала созданный pip
`conduct.exe` до выполнения `init`. Код 4551, событие Code Integrity 3077, политика
`VerifiedAndReputableDesktop`. Хеш файла совпал с хешем в событии. Файл не подписан.
Обычный CLI на этой установке не прошёл путь до открытия и закрытия проекта. Проверка
предыдущего launcher была успешной, и у него был другой хеш. Для массовой поставки
нужны принимаемый действующей политикой исполняемый файл и повторный проход на чистой Windows.
[Требования Windows к подписи](https://learn.microsoft.com/en-us/windows/apps/develop/smart-app-control/code-signing-for-smart-app-control).
