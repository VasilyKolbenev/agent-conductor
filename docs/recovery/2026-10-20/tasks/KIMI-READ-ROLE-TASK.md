# Штатная роль Kimi с одним инструментом чтения

Проверить на зафиксированном Windows EXE Kimi Code 0.38.0, можно ли передать
штатную секцию `[tools]` с единственным `Read` в фиктивную автономную ACP-сессию.
Проверить разрешённое имя и отказ для Bash, Write и механизмов делегирования
на фактическом вычислителе политики этой версии. Отдельно указать, что видно в
ответе ACP, а что установлено проверкой вычислителя. Никаких prompt, сетевой
возможности, настоящих профилей, изменений защищённой установки или dispatch.
