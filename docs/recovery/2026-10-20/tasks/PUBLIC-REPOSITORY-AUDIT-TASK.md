# Актуальность публичного репозитория

Коллега открывает корень GitHub, выбирает нужный Windows-пилот, сверяет требования,
видит текущую Studio и понимает, что можно повторить без вызовов моделей.

Проверить ветку по умолчанию и релизные теги по удалённым ссылкам, историю приёмки и
реальную доступность файлов. Проверить английскую и русскую документацию, ссылки и
иллюстрации, справку по установке, пакет, команды, примеры, режимы доступа харнессов
и план V2. Снимки делать в установленной локальной Studio на учебных данных.
Сохранить исторические свидетельства и имена CLI, которыми пользуются текущие установки.

Критерий проверки: чистая установка точных байтов из CI, переходы к исходной записи,
правка плана второй задачи, отдельный просмотр публичного релиза. Зафиксировать
границы проверки, оставшиеся красные или незавершённые проверки и владельца приёмки.
