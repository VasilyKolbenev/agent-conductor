# Claude Code в руководстве первого проекта

База `305003d8`. В обеих локалях инструкции нового проекта оператору всё ещё предлагают
подключить Claude Code через профиль, который читает адаптер. Публичная карточка этот
путь не предлагает. Имеющийся в Studio ручной обмен подтверждён на установленном wheel.

Исправить раздел настройки и повторного входа в обеих локалях. Показать официальный
личный вход, доступ по условиям региона и подписки, передачу текста через «Своя утилита»
и источник сохранённого ответа. Сохранить команды Codex и Grok и ссылку на исторический
прогон Claude. Продукт, прежние отчёты и runbook не менять.

До правки проверить, что тест отвергает прежнее руководство. После правки прогнать
проверки обеих страниц в UTF-8 и CP1251. Чтение профилей и вызовы моделей не нужны.

Дополнение после исправления страниц в `8ab4f0f9`: карточки установки Codex и Grok
ссылаются на прежнюю версию руководства. По решению ведущего обновить только адрес
руководства в карточках, закрепить полный SHA этого коммита и проверить в Chromium
обе карточки на двух языках, включая точные ссылку, имя файла и якорь раздела.
