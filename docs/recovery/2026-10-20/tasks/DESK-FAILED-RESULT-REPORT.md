# Desk — почему остановилась проверка Do

Итог — локально проверено. На Desk перед трассой появился конкретный результат
остановленного шага. Например: «Шаг „Do the work“ остановлен. Исполнитель не
изменил файлы, поэтому проверяющему нечего проверять». Раньше интерфейс показывал
общий исход проверки и пояснял значение кода 0.

Код и браузерный тест — `793f855`; задача — `8ff1afd`, дополнение после
визуального осмотра — `a3d0804`. Ветка `recovery/2026-10-20`, база `7bb106d`.

## Изменения

Сцена связывает последнюю квитанцию `action_result` с запросом того же действия и
берёт заголовок шага из плана. Основание — точная фраза штатной проверки про отсутствие
изменённых файлов. Для произвольной другой причины это объяснение не подходит.
В браузерном примере сервер сохраняет реальные записи временного проекта без провайдеров.
Для RU и EN проверены выбор задачи, расположение причины до команды запуска и переход
на другую задачу без переноса старого текста.

В совместной проверке обнаружено, что Desk озаглавливал карточку прежней квитанции
«Нужно решение» и после завершения запуска. Техлид исправил заголовок в общем
компоненте карточек. Этот же браузерный тест проверяет текст «Решение записано».
