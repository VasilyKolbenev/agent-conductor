# Проверяемый набор Kimi в отдельной папке

Сформировать в новом временном каталоге фиксированную раскладку Kimi Code 0.38.0,
Git for Windows sh.exe и msys-2.0.dll из уже проверенных локальных исходников.
Команды stage/verify сверяют состав, размеры, хеши и тип файлов; подмены или лишний
файл должны останавливать проверку. Никаких загрузок, вызовов модели, входов,
обновления настоящей описи или записи в защищённый installation root.
Сравнить 63 файла и описи защищённой v3 до/после среза. Привязка к live grant и
публикация новой защищённой описи в эту задачу не входят.

Выбран отдельный инструмент подготовки Windows-кандидата, не изменение ProcessRunner.
Опись — фиксированные байты точных входных артефактов и файлов набора. Мастер не
устанавливает программы. Временная сборка должна стать видна целиком либо отказать.
Для нативной пробы пройти verify ещё раз, запустить только shell --version в автономном
AppContainer; не делать из этого утверждение о полном наборе команд Git или подписочной
задаче Kimi.
