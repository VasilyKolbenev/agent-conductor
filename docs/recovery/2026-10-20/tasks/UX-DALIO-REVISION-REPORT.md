# Приёмка опубликованной ревизии в первом запуске Далио

Итог: локально проверено на `b350692`. Коллега может выбрать опубликованную ревизию, даже
если автор готовит следующую. Пройдены обе учебные приёмки в Chromium на русском при
ширине 375 px и на английском при ширине 1280 px.

## Что проверялось

Четыре самостоятельных запуска из чистых установок wheel прошли весь путь. В каждом
владелец ввёл задачу, добавил «План», выбрал сохранённый цикл, назначил роли через список,
просмотрел границы и разрешил работу. После Design он одобрил Do, открыл фактический
результат проверки, затем принял результат. Пять шагов записаны как `succeeded`.
Независимый checker получил файлы изменённой рабочей папки. Содержимое обоих файлов
сверено с ожидаемым. В каждой проверке использовались отдельный проект, выделенный
профиль Git и локальные двойники CLI. Ответы подписок и поведение внешних сервисов
эти прогоны не проверяют.

В этих четырёх запусках подтверждены 20 успешных шагов и 8 решений на воротах.
Для каждого запуска сохранены восемь снимков, HTTP-маршруты и `proof.json` в
`Documents/Codex/work/uxwalk-final-{ru,en}` и `uxwalk-saved-fixed-{ru,en}`.

## Отказ и исправление

Отдельно на исходном wheel коллега выбрал опубликованную ревизию с Do и checker.
Рядом хранился черновик автора следующей версии без Do. Мастер показал ошибку о
недостающем checker и заблокировал «Далее». Красный свидетель в Chromium проверил,
что после выбора отсутствовал исполнитель Do. Снимок и текст экрана сохранены в
`Documents/Codex/work/uxwalk-conflict-en/02-chosen.*`.

Мастер запоминает номер выбранной ревизии, в том числе при перезагрузке страницы.
Сервер проверяет сохранённую версию с фактическими назначениями и её бюджетом.
При подготовке мастер запускает выбранную версию. Чужой черновик остаётся доступен
автору в Library. Путь редактирования нового стартера сохранился.

## Проверки изменений

- 480 тестов прошли в UTF-8 и 480 в CP1251. Дополнительно прошли 119 проверок Chromium.
- Контроль M0 прошёл 3/3. M1 убрал закрепление номера после reload, M2 игнорировал
  назначение при проверке версии, M3 допустил номер 0. Каждый мутант привёл к падению
  своего теста. Протокол хранится в `.pytest_cache/revision-mutations/` в worktree.
- В ранних настройках свидетеля два двойника выдавали один и тот же тестовый ID.
  Для независимых ответов назначены разные ID. Также ожидание принятого решения
  привязано к записи завершения запуска, поскольку экран сохраняет квитанцию ворот.
  Указанные четыре прогона выполнены после настройки.
- Результат локальной проверки передан ведущему на ревью. Общий CI и живой подписочный
  цикл ведутся отдельно.

## Открытая находка на чистой установке

Если Git ещё не закреплён для продукта, шаг материалов указывает команду настройки.
Кнопка «Далее» остаётся доступна. В конце подготовки сообщение предлагает обеспечить
наличие репозитория даже при уже существующем репозитории и коммите.
Снимки приведены в `Documents/Codex/work/uxwalk-base3/01-goal-material.png` и
`04-prepare.png`. Во всех завершённых учебных прогонах Git был закреплён в отдельном
профиле. Обратная связь о настройке Git и диалоговый запуск V2 остаются отдельной работой.
