# Проверяемые контракты

1. Строка с именем устройства сохраняет точное написание. Для уже абсолютного
   WindowsPath входная строка определяется os.fspath() перед вызовом extended().
   Проверить оба случая на 3.11 и 3.12. Выбор ожидания по версии Python скрыл бы
   изменение написания реального входа. Исходный код extended() сохраняется.
2. В браузерном сценарии Do сравнить полный набор account/verification записей
   с ожидаемыми ролями, идентичностью и вердиктом независимого checker.
   Отбор только строк с checker не обнаружил бы пропажу account evidence.
   Действительный патч, единственный запрос и проверки инспектора остаются частью
   того же сценария. Использовать только автономную тестовую CLI.
3. По фокусу сначала воспроизвести поведение с тем же режимом запуска Chromium,
   сравнением родительского и дочернего документа, текущего элемента и консоли.
   По результату отдельно выбрать место исправления. Логи и временные файлы
   сохранять в Documents/Codex/work/ci-followup-1113 вне Git.

4. Проверить гипотезу исчезающего инспектора. Между первым ответом identity и
   выбором сессии кнопка памяти уже доступна. При выборе первой сессии switchTo
   закрывает открытую панель. Удержать событие открытия соединения в существующей
   browser fixture, проверить состояние кнопок до загрузки и работу после неё.
   Если подтверждено, связать доступность кнопок памяти и квот с готовностью данных
   проекта в HTML и paint(). Остальные переходы между сессиями остаются прежними.
   Альтернатива ожидания в layout-тесте не исправляет первый клик пользователя.
   Root владеет arachnid.html, arachnid.js и test_arachnid_reconnect.py.
