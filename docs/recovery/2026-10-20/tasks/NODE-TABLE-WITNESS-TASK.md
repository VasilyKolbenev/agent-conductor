# Один замер таблицы процессов во время таймаута Node

На `4120c38` в журнале 5-секундный вызов tasklist завершился TimeoutExpired.
Повторный вызов из теста под другим дедлайном позже успешно прочитал таблицу. Тест
приписал его ответ предыдущему вызову; поведение приложения и предел запроса не менялись.
Зафиксировать результат того же вызова ОС и независимо сравнить его с заметками timed-out
процесса. Сохранить единственный запуск, не добавлять повторов, увеличить покрытие
неуспеха контролируемым таймаутом и проверить реальный путь Windows.
