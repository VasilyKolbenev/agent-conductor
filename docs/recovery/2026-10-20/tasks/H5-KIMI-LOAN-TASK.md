# K2b.1 — передача identity в реальный Windows loan

Подписочный dispatch не активировать. Использовать проверенный K2a примитив создания от parent handle, фиктивный профиль, проверенный архив Kimi Code 0.38.0 и настоящий networkless ProcessRunner. Доказать, что identity, полученная создателем, проверяется по handle, которым выдаются права, до изменения DACL. Подмена должна отказать без предоставления прав объекту-заместителю.

У держателя AppContainer должны читаться credential и config, попытки записать или переименовать credential или создать файл в домашнем каталоге должны быть запрещены Windows ACL, а запись в отдельный штатный scratch разрешена. Выполнить оригинальный ACP initialize/authenticate на том же пути и отличить штатный result от пустого выхода. Нет доступа к аккаунтам/модели и не расходуется подписка. Старые три snapshot и их grants не изменяются.
