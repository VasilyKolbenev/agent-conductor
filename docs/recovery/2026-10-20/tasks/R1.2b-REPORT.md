## Изменения

Файлы: `src/conductor/command/seed_routes.py` (283 → 288 строк, самая длинная 100),
`src/conductor/command/policy_driver.py` (319 → 325, самая длинная 158 — старая строка `_proposal`,

строки в конце). `git diff --stat` по трём изменённым: 3 файла, 26 вставок, 14 удалений.

1. `SeedSettler.settle` отвечает `True` для run, в журнале которого стоит `RunTerminal`: проверка
   `standing_terminal(recovered)` идёт первой после чтения журнала, остальной код и кортеж `except`
   не менялись. Это тот же предикат, по которому хранилище отказывает завершённому run (`RunClosed`)
   и история авторизации отказывает pause/revoke. Docstring класса обновлён.
2. `_next_node` спрашивает слово плана (`schedule`, `run_state != "open"`) до `failure_sources`.
   На открытом плане порядок «running, unknown-отказ, кандидаты» прежний. Добавлен docstring.
3. Docstring `_seed_owed` расширен перечислением «run, записавший свой конец». Код `_seed_owed`,
   `_tick`, `_admit_next`, `_select_next` и `TICK_SECONDS` не менялись.
4. Тесты скопированы файлом без правок (хеш ниже). Четыре теста (A, B, C, D) закрепляют освобождение
   слота при потерянном seed у result gate, при потере внутри окна под затвором `HeldTick`, при seed,
   не устроенном с начала, и при `unknown` с последующей коррекцией gate. Два контроля (E, F)
   закрепляют неизменность поведения на открытом плане.
