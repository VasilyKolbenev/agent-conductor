# Начало работы в пустом проекте Studio

На пустой главной странице рядом с вопросом о результате есть одно основное действие, ведущее в мастер новой задачи Desk. Список задач появляется, когда есть что показать. Создание простой записи доступно в раскрываемом блоке. Карта и история проекта убраны под отдельное раскрытие. Загрузка и отказ чтения имеют свои состояния. После появления первой задачи начальный экран переключается на реальные данные проекта.

Браузерная проверка сначала обнаружила отсутствие целевого входа на пустой главной. После изменения пройдены сценарии с активным пустым проектом, режимом просмотра, ошибкой чтения, переходом клавиатурой и изменением состояния проекта. Интерфейс проверялся на ширинах 375 и 1280 пикселей. Учебная среда обходится без аккаунтов. Код в `08a0587`, объединённая сборка `1e1117a8`.

Пользовательский путь описан в [первом запуске](../../../first-run-v1.md). Общая проверка интерфейса на объединённой сборке зафиксирована в [передаче за 8 ноября](../HANDOFF-2026-11-08.md).
