# Две задачи коллеги в новом Windows-пилоте

Коллега указывает две свои задачи. Для первой он записывает действительно выполненные
проверки и результаты в исходном порядке и принимает запись. Открыв вторую задачу в
Studio, он просит Колоса найти этот порядок, открывает источник и меняет план в чате.
Формулировки, шаги и результаты выбирает коллега. Проверить весь путь из передаваемого
ZIP в чистом Windows-окружении, без подписок, внешних запросов и вызовов моделей.
