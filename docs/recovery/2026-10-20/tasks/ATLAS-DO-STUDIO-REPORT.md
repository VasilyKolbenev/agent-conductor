раскрытие файла вне seed, потеря всей панели при пустом assertion, дополнительная

## Повторное открытие локального примера

На рабочем ноутбуке сохранены два отдельных проекта. После перезагрузки ноутбука
их можно открыть снова. Выполните первые две строки и одну из команд ниже.
Для второго сервера используйте отдельное окно PowerShell. Каждый сервер
штатно останавливается через Ctrl+C в своём окне.

```powershell
$kit = Join-Path $env:USERPROFILE 'Documents\Codex\work\studio-action-1109'
$python = Join-Path $kit 'd3b9e8a\env\Scripts\python.exe'
& $python -I -B -X utf8 "$kit\studio-serve.py" view "$kit\accepted-dalio" 7828
& $python -I -B -X utf8 "$kit\studio-serve.py" active "$kit\utility-project" 7829
```

Откройте [принятый цикл](http://127.0.0.1:7828/#screen=runs&task=task-dalio-patch&run=dalio-patch&lang=ru)
или [участников учебного проекта](http://127.0.0.1:7829/#screen=agents&lang=ru).
В этой поставке демонстрационные проекты используют пустой реестр исполняющих адаптеров.
