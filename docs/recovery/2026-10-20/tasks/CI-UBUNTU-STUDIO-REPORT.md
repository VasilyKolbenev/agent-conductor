## Home Repo и Arachnid

[Мэтт Покок](https://www.aihero.dev/the-home-repo-pattern) предлагает хранить общие правила
и ссылки на проекты в одном Git-репозитории. Инструкции и команды, относящиеся только
к конкретному проекту, остаются в этом проекте.

В разработке Arachnid уже есть один WORKING-STANDARD и указатели AGENTS.md/CLAUDE.md.
В продукте Hub регистрирует проекты, а документ задачи привязан к конкретной версии
в Git. По умолчанию инструкции агента не переносятся в рабочую копию задачи.

Предложение для V2: оператор подключает версионированный каталог общих материалов.
Например, для изменения поля заказа в API и клиенте Атлас показывает два проекта,
версию общего контракта и участвующие инструкции. Для каждого репозитория отдельно
видны исходный коммит, предполагаемые изменения, тесты и приёмка. Для первой проверки
достаточно подготовить этот план и посмотреть, какие уточнения потребовались оператору.
Это кандидат для обсуждения после альфы.
