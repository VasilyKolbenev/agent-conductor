# Доказательство результата локального Git-подтверждения

На чистом `1e1117a` официальный браузерный порядок увидел локальную ветку и receipt, но не увидел строку Created commit за пять секунд от нажатия. Задание ограничено тестом этого пользовательского пути. Проверить отдельно завершение именно POST подтверждения и появление его результата в карточке. Выполнить положительный контроль с задержанным ответом и перечитыванием того же запуска. Сохранить проверку реального Git ref, исходного HEAD, опубликованного снимка и единственной записи. Обычная ошибка HTTP или отсутствие отрисованного результата должны оставаться красными.

Образец красного наблюдения `C:/tmp/b1e111f/test_desk_accept.stdout.txt`. Исходный упавший модуль не повторять. Для диагностики использовать новый локальный сценарий с управляемым моментом ответа.
