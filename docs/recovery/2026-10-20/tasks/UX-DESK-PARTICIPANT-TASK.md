# Первый запуск без подключённого подписочного участника

На этапе команды показать краткое конкретное действие. Владелец открывает
существующие инструкции в соседней вкладке, сохраняет вкладку с задачей
и после настройки вправе перечитать реальный состав доступных харнессов.
Цель, материалы и ручной выбор не требуют повторного ввода. Успех подключения
устанавливается только по новому ответу этого же проекта.

Проверить на RU/375 и EN/1280 с двумя действительно разными учебными процессами
на одном порту. Использовать фиктивно настроенный подписочный провайдер, без входа
в личный аккаунт и без вызова модели. Не менять договоры подключённых провайдеров
и действующие возможности запуска с другими источниками.
