# Переносимая опись Windows-комплекта Kimi

На базе `8d82947` подготовить опись точного трёхфайлового кандидата Kimi Code
0.38.0 для сравнения сборки и локальной установки. Запустить её на чистой копии
официального локального ZIP Kimi и уже измеренного локального набора shell.
Опись должна привязать версию, архитектуру, относительные пути, точки входа и
проверенные байты. Перенос каталога сохраняет отпечаток. Неполный или изменённый
набор останавливает выдачу описи.

Сценарий автономный: только временные папки и чтение файлов. Не затрагивать
защищённую установку, данные входа, сеть, grant и dispatch.
