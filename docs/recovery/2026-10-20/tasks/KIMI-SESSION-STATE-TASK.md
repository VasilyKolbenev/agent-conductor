# Локальная сессия Kimi до prompt

Срез после K1b, K2b и H5-KIMI-PROMPT-OFFLINE. Проверить отдельный критерий:
получаем ли от нативной Kimi Code 0.38.0 корректный ответ с идентификатором ACP
`session/new` до любой задачи. Предыдущая проба остановилась на authenticate.
Вход только синтетический, сеть контейнера выключена. Один учебный проект,
ни одной команды модели, установки или входа в личный профиль.

Сначала home только для чтения. При отказе — отдельный процесс, где неизменяемые
config и credentials находятся в тестовом scratch. Сравнить тип результата,
класс ошибки, разрешённые имена/операции, сохранность исходной копии и уборку.
При достаточном сигнале по одному изменению сузить writable область. Ошибки без
точного свидетельства не считать доказательством необходимости отдельного файла.
Если ACP-проверка не воспроизводит ограничение prompt, записать границу вывода;
новых прав продукту и живого dispatch это задание не даёт.
