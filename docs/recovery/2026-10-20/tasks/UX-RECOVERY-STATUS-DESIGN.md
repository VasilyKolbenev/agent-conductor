# Сохранить подтверждённый код владельца

Проверка `ProjectOwner.check()` сообщает типизированный `OwnerRefused("recovery_required")` при неподтверждённом возврате ресурса. Обвязка ограниченной работы стирает его, преобразуя в общий `AuthorizationError`. Сохранить этот единственный случай в типе, совместимом с существующим отказом записи. Чтение при текущем разрешении использует существующий `restart_required` и отдельную причину. Сохранить обычное различение владельца, просмотр без драйвера, завершённость и окончательные состояния. Подтверждать через HTTP на учебном проекте с явной подстановкой этого отказа, не приписывая причину операционной системе и не запуская восстановление.
