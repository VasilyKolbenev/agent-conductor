# Do на Windows: запись без вызова модели

Проверить Codex 0.164.0 в синтетической папке задачи. Исходная сборка продукта
`c8d48abc9874`, предшествующие измерения в HANDOFF-2026-11-08.md.
Различить доступ патчера, ограничения команд самого Codex и результат dispatch.
Проверить обычный путь `codex exec`, включая применение патча по фиктивному ответу,
если это допускает изоляция. Сверить байты внутри и за пределами области, проверить
read-only, уборку и отсутствие оплачиваемых обращений. Конфигурация только в одноразовых
каталогах. Политики и доступ к корню хоста не расширять. Если кандидат не запускается,
записать воспроизводимую причину, состояние файлов и границы проверки.
Не продолжать живой Далио по результатам синтетического теста.
