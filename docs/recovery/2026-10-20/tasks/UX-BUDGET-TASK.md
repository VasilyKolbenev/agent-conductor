# Рекомендация границ запуска по задаче

Новый запрос предпросмотра может попросить сервер предложить границы по замороженному
плану и опубликованным входным документам. Старый пустой запрос и пять ручных полей
сохраняют контракт. Ответ должен объяснять количество рабочих шагов, исполнителей,
проверок, объём исходных материалов и резерв при отсутствии сопоставимой истории.
Глубина проверки выбирается человеком. Попытки, обязательные проверки, ограничения
графа и границы установки остаются в силе. Рекомендация до явного разрешения не пишет
в журнал, не запускает harness, не обещает длительность или расход подписки.
Уже выданные границы режим рекомендации не расширяет.

Покрыть HTTP-вход настоящего предпросмотра и первый путь через мастер Desk. Показать
причины и изменение рекомендации владельцем до разрешения. Не читать файлы задачи
или передавать тексты модели ради подбора времени.
