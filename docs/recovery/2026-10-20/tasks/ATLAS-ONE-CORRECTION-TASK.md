# Один разрешённый возврат на доработку Do

На экране предложения нового плана оператор может явно разрешить одну доработку
результата после замечаний независимого проверяющего. Существующее значение по умолчанию
и уже сохранённые планы сохраняют свой бюджет. Новая опция не выдаёт разрешение.
До выпуска проверить привязку выбранных условий, восстановление и фактическую передачу
замечаний в последовательности с подготовкой патча на тестовых двойниках.
