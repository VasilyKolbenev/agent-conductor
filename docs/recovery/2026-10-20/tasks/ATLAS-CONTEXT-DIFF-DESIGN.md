# Третья реплика в контексте передачи

Вариант с выбором последнего Do по имени теряет связь между планом, действием и попыткой.
Используем закреплённое продолжение передачи и уже существующую проверку matchesAtlasAttempt.
Один проверенный ответ API питает оба представления. Выбор файла меняет только diff.
В чате показать путь и выдержку из изменений; полный diff и источник тестов доступны справа.
Если связь неоднозначна, нужен выбор. Недоступные изменения отображаются по статусу источника.
Отмена чтения и смена сессии должны исключать поздний ответ чужой попытки.

Проверить через чат три последовательные фразы, совпадение строк с сохранённым diff,
тот же протокол и сохранность предыдущих реплик. Проверить ширину 375 px и обычный
экран, отсутствие исполнения и совпадение журнала до и после. Назначение отличается от
обычной команды открытия вкладки diff, которая доступна также вне контекста передачи.
