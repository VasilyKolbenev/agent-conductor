# Редактор открывается рядом с мастером

Редактор Studio уже принимает новый процесс с нуля или из стартового шаблона. Открыть его в текущей вкладке означало бы потерять ещё не записанную задачу. Ссылка открывает тот же проект в соседней вкладке с нужным языком, без передачи текста черновика. Процесс публикуется штатным редактором.

В первоначальной вкладке человек явно перечитывает опубликованные циклы через существующее событие мастера для каталога процессов. В карточке выбирается фактически полученная ревизия. Черновики и отказ чтения не становятся доступной опубликованной версией; запись задачи, создание запуска и разрешение исполнения принадлежат следующим шагам мастера.

Через браузер будут проверены сохранение введённого результата и материалов, публикация ранее отсутствовавшего процесса, чтение и выбор его ревизии в той же вкладке. Подмена внешней модели не нужна.
