# Вопросы над одним черновиком

1. Начало — поле результата, пример, переход вперёд. Название выводится существующей
   функцией из первой строки; ручной заголовок сохраняется. Не предъявлять коллеге
   несколько необязательных анкет одновременно. Настоящее препятствие настройки Git
   должно оставаться видимым на первом экране.
2. Если проект уже сообщает доступный источник, сразу перейти к команде. Если нужно
   выбрать пустую рабочую папку либо настроить источник — показать один вопрос про
   файлы и ответ о результате с кнопкой изменения. Материалы и критерий доступны
   по желанию. Используются обычные стадии `task/materials` и значения той же формы.
3. Команда показывает фактическое предложение и его основание. Для прежнего/закреплённого
   цикла показать источник, для Далио по умолчанию — назначение последовательного цикла
   и проверки. Для назначений использовать данные `assignmentView`. Подтверждённые
   ответы представлены как ответы; следующий вопрос относится к первому недостающему
   назначению или указанию. Подробные поля по-прежнему доступны.
4. Преподготовка, просмотр и разрешение остаются существующими действиями. Внешняя
   панель подписочного совета подключается отдельно через необязательный обработчик
   экрана цели. Без него нет элемента, соединения или запроса.

Не вводить чат с собственной копией ответов. Мастер обозначает себя как локальный
интерфейс постановки задачи. Наследуются текущий черновик и контракт human gate.
Программа проверяется через открытие «Новая задача», исправление, переход в поля,
возврат к вопросам и достижение предпросмотра на учебном сервере.
