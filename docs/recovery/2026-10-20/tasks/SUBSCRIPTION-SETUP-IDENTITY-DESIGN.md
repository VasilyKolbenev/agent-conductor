# Subscription card facts live with the owning transport

At `305003d8` the identity gate reported five comparisons in three neutral modules.
There are four independent responsibilities: CLI selection, executable and full-tree
inventory, accepted login/configuration forms, and forbidden external machine inputs.

Use an optional typed Windows subscription installation on the two adapter classes,
discovered through the existing provider catalog. The version comes from the same
reviewed profile the transport already uses. A third adapter needs to declare its
own reviewed installation to become selectable. A second fixed registry inside the
wizard would require simultaneous edits and could admit a card the adapter cannot run.

The declarations carry exact executable and inventory, accepted extra login entries
and decoded configuration forms. Codex also supplies exact ProgramData paths and the
machine policy key. The common verifier checks the declared paths and the 64-bit HKLM
view; missing inputs pass, other lookup errors propagate. Its path traversal, ACL
rights, ownership and full-tree verification stay in force. Parser conversion returns
a fixed safe list in its error so an invalid value cannot be echoed.
