# Учебная задача на чистой установке

На отдельном Windows wheel от e73ce8d создать задачу через Studio, открыть её учебный
результат и принять его. Сделать явным, что пользователь проверяет фиксированный пример
счётчика. Просмотр не записывает решений. Подтвердить в новом профиле Chromium и после
перезагрузки. Ширины 375 и 1280, русский и английский. Реальные harness не вызывать.

Для временного проекта conduct demo опубликовать отдельную учебную ревизию с одной
проверкой человека. Привязать запуск обычным редактором записей к созданной задаче.
Пустой состав допускается только для этой точной ревизии в demo, на confirm и с задачей;
сервер сверяет содержимое ревизии. Обычные установки сохраняют существующие правила.
Кнопка открывает стабильный запуск задачи; повтор возвращает ту же запись.
Измерить отсутствие запросов исполнения, проверить отказ за пределами демо.
Пример выпуска, защищённую установку и живой цикл Далио не использовать для записи.
