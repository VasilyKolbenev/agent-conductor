# Учебный Далио с проверяемым Do

Пройти полный цикл приложения на проверенном wheel кода `2f983e9`. Учебные исходники —
из прежнего трижды хешированного примера со счётчиком. Новый корень проекта и новое
разрешение. Старый запуск не воспроизводить и его решения не переносить.

1. Сверить полный локальный Windows-барьер для установки и содержимое wheel.
   Установить точный SHA под защищённым корнем и пройти проверку закреплённых CLI.
2. Подготовить отдельную ревизию из прошлого опубликованного плана. Обычный JSON для
   Grok Diagnose. Do получает исходный бриф и план, готовит патч, приложение применяет
   его только в копии задачи. Отдельный экземпляр Codex проверяет фактические изменения.
3. Проверить роли и подписочные входы, происхождение исходников, предпросмотр и остатки
   до разрешения. Один запуск, пять действий, одна попытка на шаг, 600 секунд на
   исполнителя и ещё 600 для checker. Порог Codex владельца — 20% остатка.
4. От имени `codex-test` сверить план до допуска Do. Приёмка результата — только при
   подтверждённых исходных и итоговых хешах, положительном независимом свидетельстве,
   тестах и совпадении с контрольным примером. Не переносить решение на иные проекты.
   Исходный репозиторий не обновлять. При сбое записать причину и сохранить артефакты.
5. Параллельно проверить понятность открытия результата Do для коллеги и онбординг
   подписочных harness. В отчёте отличить реальные подписочные запросы от локальных
   двойников и от проверок, которые требуют участия владельца.
