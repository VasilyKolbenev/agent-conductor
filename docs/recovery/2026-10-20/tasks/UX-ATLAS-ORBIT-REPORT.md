## Мутанты

Контроль на изолированной копии — 6 passed. Каждый вариант упал на целевом сравнении;
после каждого восстановлены и сверены исходные байты файла.

| Поломка | Что покраснело |
| --- | --- |
| Пустая орбита | Нет пяти доступных шагов |
| Вопрос открывает другой тест | Нет ожидаемого утверждения |
| Отключён выбор файла | Потеря ожидаемого diff тестов |
| Инспектор остаётся доступным за открытым меню | Нарушен порядок клавиатурной навигации |
| Вопрос о приёмке показывает diff | Не выбрана вкладка проверяющего |
| Подмена одной строки снимка | Не совпал SHA исходного файла |
