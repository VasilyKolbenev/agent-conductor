# Grok ACP diagnostic contract

G6-ACP-1, 2026-11-02. Admit a dedicated, one-shot operational capability for this
reviewed Grok build. Keep the application's routine quota and dispatch contracts as
they are. Unlike adding authenticate to every quota read, this limits it to the
single run the owner requested. Install the reviewed probe by hash in the protected
operator tools directory and execute with the verified installed Python in isolated
mode. The caller supplies no payload, argv, path or account value.

Only the pinned executable and the standard no-update stdio agent are admitted. Use
the verified local project, a newly created empty read-only work directory, the existing
secret-only relay copy and a Windows review AppContainer. The fixed wire contains
initialize, auth/info and authenticate with cached_token and headless=true. Close on
response 3. No prompt, session/new, model listing, refresh command or task permission.
Reserve a single receipt before the CLI runs. Fail closed if the pin, protected host,
lease, freshness or relay cannot be established. Keep the original credential out
of the container. Compare its digest afterwards and inspect cleanup even on failure.

The decoder requires the proven cached-token method, matching response IDs and a
well-formed gate. A gate with a nonempty message means the CLI reported a restriction.
If the field is absent, support remains unconfirmed. Authenticate errors, uninterpretable
data, timeouts, and secret echoes are inconclusive; do not log their payloads. The
synthetic tests must detect a prompt on the wire, malformed or duplicate responses,
spurious success and copying arbitrary remote messages or URLs into the report.
