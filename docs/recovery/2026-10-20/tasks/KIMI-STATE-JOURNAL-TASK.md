# Kimi W3a: владение временным состоянием

Для следующей проверки Kimi выделять дерево изменяемого состояния в настоящем
Windows ProcessRunner с долговечной идентичностью и возвратом прав после сбоя.
Вход — внутренняя явная опция локальной review-попытки с уже проверенным
readonly_home_identity. Продуктовый dispatch, сеть и чтение/копирование реального
токена в этот срез не входят. Исходный источник и stage должны оставаться только
для чтения или полностью недоступными контейнеру.

Проверить создание/запись/удаление обычного состояния; отказ записи в источник
и защищённую вложенную папку; восстановление после допустимого restart proof;
остановку до удаления при подмене записанной identity или ссылке. Старые ACL-записи
и профили должны сохранять прежнее поведение. Отдельно указать барьер происхождения
shell: тестовый хеш бинарника не авторизует его живую установку.
