# Сравнение старого счётчика по запечатанным материалам

Берём до-образ из закреплённой Git-базы этой попытки и тест из её снимка. Не запускаем
Python из материалов проекта. В отличие от подсчёта по строкам diff, AST различает список,
вложенные элементы и выражения; неоднозначный случай оставляем без вывода.

1. Первый источник: отображаемый изменённый модуль, прежняя однозначная функция с одним
   return len(аргумент) и однозначный вызов её из проверки. Вход — список литералов,
   ожидание — целое; присваивания, меняющие смысл, и неполные доказательства не допускаются.
2. Передаём опциональный old_length только у соответствующего tests.cases[i]. В нём
   expression, function, path, line прежнего return, actual и expected. Клиент различает
   отсутствие расчёта, совпадение и несовпадение. Сохраняются привязка к попытке и правила
   скрытия файлов. Никаких eval, импорта или исполнения содержимого, дополнительных команд.
3. Второй источник: исходные строки протокола принятого Do. Это свидетельство новой версии.
   Предположение о старом результате не представлять как произошедшее падение.

1.4. Реальный тест импортирует функцию через пакет. Подтверждаем прямой реэкспорт
по __init__.py в закреплённом дереве; проверка соблюдает разрешённые пути и лимиты
общего чтения. Если архив не содержит объект или цепочка неоднозначна, связи нет.
Чтение на том же снимке использует прежний режим: offline не запускает Git.

Проверки: реальный вход, отрицательные варианты и изменённая база через публичный шов,
цепочка из шести реплик, посторонняя попытка, отсутствие данных; локальная Studio
на двух ширинах, хеш принятого журнала до и после. Полную матрицу выпуска не запускать.
