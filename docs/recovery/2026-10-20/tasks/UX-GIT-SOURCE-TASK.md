# Источник файлов при первом запуске

Коллега открывает существующий репозиторий на чистой установке. Закреплённый Git
пока недоступен. Мастер должен отличать эту ситуацию от пустой папки на первом
экране и подсказать, как продолжить с теми же ответами и материалами.
Профиль Git, установка, проект и сервер пользователя не меняются.

Проверить RU/375 и EN/1280 на настоящем сервере с отдельным тестовым профилем.
Сначала зафиксировать красный результат. Затем закрепить уже установленный Git
только в учебном профиле, переоткрыть учебный проект и проверить фактическую
рабочую копию задачи. Проверить явный выбор пустой папки независимо от этого.
