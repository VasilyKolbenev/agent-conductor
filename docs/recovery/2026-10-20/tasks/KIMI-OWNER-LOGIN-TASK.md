# Сохранить закреплённый Kimi при входе из мастера

Путь коллеги: установить проверенную 0.38.0, выполнить команды `conduct providers`
по подписке и понимать, когда доступны только метаданные. На базе 1c7d0a2
профиль K1a задаёт `KIMI_CODE_NO_AUTO_UPDATE=1` дочерним процессам,
но мастер передаёт владельцу только назначение `KIMI_CODE_HOME` и `kimi login`.

Сохранить закреплённую версию при выполнении ровно тех команд, которые напечатал мастер.
Использовать тот же выключатель, что и профиль K1a; оставить остальные подключения
неизменными. Обновить EN/RU путь к архиву и результаты для четырёх подписочных harness.
Не менять границы исполнения и не выполнять вход, скачивание или запрос к моделям.

Дизайн: мастер печатает установки окружения для отдельной оболочки владельца.
Выключатель принадлежит профилю Kimi. Не создавать обёртку вокруг CLI и не запускать
авторизацию из приложения. Через настоящий мастер подставить собственный временный
исполняемый файл, проверить, какие argv и переменные получила от его текста оболочка.
На исходной базе намеренно поставить флаг в 0; новая команда должна заменить его на 1.
Проверить обе кодировки Windows и POSIX-представление. Артефакты вне репозитория.
