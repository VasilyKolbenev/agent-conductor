# Подключение харнесса как утилиты

На экране участников рабочей Studio нужна кнопка добавления харнесса. Claude Code и
Kimi Code должны быть явно доступны рядом с Codex и Grok. Дать оператору подключить
также свою утилиту, сохранить подключение и снова открыть его после обновления.
Показывать реальные доступные действия. Название или путь сами по себе не доказывают
подписку, квоту, совместимость или разрешение выполнять задачи.

Использовать существующую модель провайдеров и безопасную границу локального проекта.
Согласовать способ подключения собственных утилит с доступными интерфейсами. Проверить
обычный экран и сохранение, режим просмотра, ошибочный или повторный ввод и отсутствие
неявного вызова CLI. Для установленного Kimi отдельно проверить локальную доступность
без чтения секретов и платного запроса. Его живую проверку владелец отложил.
