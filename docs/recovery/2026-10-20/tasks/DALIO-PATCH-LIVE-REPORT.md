## Приёмка результата

В рабочей копии изменились `runstats/counts.py` и `tests/test_counts.py`. Проверка сравнила байты обоих файлов с архивом проверяющего. Хеш снимка — `sha256:a571e89f5e372830d6a8dd089dfb45af8c3ed1051d81a653b69f7728a91ed415`. Исходный коммит учебного проекта — `3633a884e20831530f0f0c92f98f094d96edcf7a`. Исходные файлы и `runstats/__init__.py` сохранили исходные хеши.

В отдельном Windows AppContainer без сети прошли все семь тестов результата. Пять независимых примеров дали `0, 2, 1, 0, 2`; входные данные сохранились. На первоначальной реализации те же семь тестов зарегистрировали 30 проваленных проверок, включая подслучаи unittest. Смешанный список из двенадцати элементов раньше давал 12, после правки даёт 2. Только после этой сверки записано итоговое решение.
