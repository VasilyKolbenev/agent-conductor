# ALPHA-LANDING

Подготовить Windows Studio к передаче по результатам аудита от 16 ноября.
Живая приёмка Kimi требует отдельной проверки на подписке владельца.

1. Воспроизвести ошибку квитанции на глубоком Windows-пути с кириллицей. Записать
   первую и вторую задачи, открыть обе повторно и проверить источник процедуры.
2. Из каталога показать путь подключения личных Codex и Grok. Сохранить раздельные
   подтверждения подключения и исполнения. Указать фактические возможности всех карточек.
3. Сверить инструкцию оператора на обоих языках и подписи ручного обмена с продуктом.
4. На одном кандидате проверить код, поставку и путь оператора. Отдельно отразить внешние
   проверки, для которых нужны другой человек, подписка или решение поставщика.
5. В продуктовом плане перечислить уже поставленные части V2, изменения кандидата
   и дальнейшие направления с наблюдаемым критерием готовности.

Сохранить опубликованный Pilot 2. Граница этой работы — подготовка к выдаче.
