# Открытие результата Do

Цель кнопки зависит от наблюдаемого действия. Для последнего подтверждённого Do
нужна его квитанция; для обзорного шага с сохранённым документом — этот документ.
Для результата без документа остаётся квитанция. Фокус должен перейти вместе
с видимой областью, в том числе если использовали клавиатуру.

Выбран существующий журнал и отображение рабочего каталога по подтверждённому запросу.
Альтернатива — новый серверный маршрут для чтения файлов; он не восстановил бы
исторические байты по давнему запуску и изменил бы контракт. Не вводить его здесь.
Связь проверяется по action/attempt, evidence_refs и verifier_instance_id узла.
Учитывать последнюю попытку шага, чтобы предыдущая проверка не выглядела текущей.

Шов браузерной проверки — реальный сервер с фиксированными ответами внешнего адаптера;
шов отрицательных проверок — та же карточка со старой попыткой и недоказанным исходом.
Проверка ограничена этим переходом и не доказывает доступ к подписке.
