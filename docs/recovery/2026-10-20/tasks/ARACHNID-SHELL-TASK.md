# Основное рабочее пространство Arachnid

При обычном открытии корня локального проекта оператор видит фирменную оболочку
из утверждённого макета. Слева настоящие сессии и задачи проекта, в центре чат
Атласа с орбитой выбранного цикла. При выборе Do справа открываются материалы
выбранной попытки. Чат и черновик остаются видны на широком экране.

Перенести в рабочую поставку визуальную иерархию макета, подключение харнессов,
выбор сессии, контекст участников, лимиты по запросу и историю текущей сессии.
Для новой задачи оставить достижимым штатный путь подготовки. Пустой проект,
отсутствие показаний или недоступность сервера имеют собственные состояния.
Сцена читает реальные записи через штатный transport. Прототип с учебными
JS-данными в runtime не поставляется. В этом срезе разбор Атласа локальный.

Существующие команды управления запусками, публикация, решения владельца и ссылки
Desk/Hub остаются доступны. Старая ссылка с явно названным экраном сохраняет свой
контекст и назначение. Проверить на изолированной копии принятого Codex + Grok
по корневому URL установленного wheel. Не запускать модель, не изменять исходный
принятый проект, остановиться при 30% остатка недели.
