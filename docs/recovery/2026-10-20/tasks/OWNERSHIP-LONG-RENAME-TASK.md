# Закрытие квитанции входа по длинному пути Windows

Исправить только системное имя назначения в перемещении по открытому handle.
Сохранить начальную и конечную проверку identity и отказ замены существующей цели.
Воспроизведение на 1e1117a: отдельный проект длиной 80 символов, разрешённый
внешний auth-home длиной 144, квитанция закрытия длиной 263. Фиктивная попытка
советника заканчивается unknown до ответа CLI из-за WinError 206.
Проверить нативное перемещение, коллизию алиаса, закрытие реальной lease и
прежние ownership tests. Настоящие входы и dispatch не требуются.
