# ALPHA-LANDING — решения и проверка

Базовый SHA аудита — `8d82947`. Публичная точка сравнения — Windows Pilot 2.

## Хранение

Сначала воспроизвести сбой через создание задачи, затем применить уже используемое
представление длинного пути на границе Windows I/O. Проверить атомарность квитанций,
повторное открытие, кириллицу и короткие пути. Изменение Windows Registry не требуется.

## Подключение

В карточках использовать проектные наблюдения о конфигурации и доступности;
роль, источник квоты и границы проверки показывать отдельно. Путь и право на запуск
закрепляет локальная команда владельца. Выбор провайдера ограничить известными
адаптерами, повторно использовать проверки установки и блокировку проекта или профиля.
Проверить отмену, отказ и ошибки настройки с помощью двойников. Сохранить read-only просмотр,
ручной обмен и совместимый мост. В браузер и журналы не передавать данные входа.

## Приёмка

Сопоставить RU/EN с принятым циклом и актуальным каталогом. Проверить с чистой поставки
работу двух задач, источник, карточки и чтение доказательств Do. Различать локальный
тест, наблюдение реального поставщика, результаты CI и опыт внешнего коллеги.
Закрытие полной альфы требует внешних результатов из плана ALPHA-FOUR.
