## Что изменилось

Atlas показывает перед разрешением имена файлов из задачи человека и записывает их
в связанную с разрешением инструкцию Do. Старые инструкции открываются с исходными
байтами и прежним объёмом доступа. Содержимое плана модели не добавляет путей.
Адаптер проверяет рабочую папку задачи, обычный файл, размер, тип текста,
защищённые значения и хеш начального снимка. Codex получает эти данные на stdin
до подготовки патча. Для нового файла с отсутствующим путём передаётся отметка
об отсутствии.
