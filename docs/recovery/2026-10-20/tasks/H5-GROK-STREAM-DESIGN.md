# Per-review Grok wire selection

The graph argument is a closed literal on DeepReviewArgs. Existing Studio
advanced arguments and the workflow draft API can author it. The graph digest,
proposal and request include it. The field is omitted from older documents.
Use the same authorization boundary, executable pin, read-only task file, and
capture/leak checks. Do not switch every diagnose node or change the default
format in provider facts. Do not store selection on a shared adapter instance.
Reject other providers before a task can spawn. Bind the versioned format
semantics to the marked review and show the override in the grant preview.

Diagnostic output is streaming-messages-json without partial events. Treat it as
bounded strict NDJSON (48 KiB). Require an ordered unique init and terminal result.
Success requires a matching nonempty session, exit 0, end_turn, no reported error,
and a coherent terminal text. Concatenate the direct text blocks from every top-level
assistant message in order without inserting separators, normalizing whitespace,
or appending the terminal duplicate. The terminal result corroborates the last
assistant text according to the pinned reducer. Thinking and tool results stay
out of the artifact. Unsupported or ambiguous output, truncation or a credential
echo fails closed. Errors never produce artifacts or expose identifiers.

Report valid nonzero errors as either "the Grok diagnostic reported an opened session
before the error" or "the Grok diagnostic reported no session ID before the error".
For invalid streams use "the Grok diagnostic stream did not establish a result".
Do not interpret these observations as a model call or a billing fact. A verified
successful artifact in this mode also requires the nonempty session witness.
