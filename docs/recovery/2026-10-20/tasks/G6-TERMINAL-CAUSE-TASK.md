# Preserve an actionable cause after a Grok session opens

Keep the phase witness and a closed cause when the Messages terminal supplies one.
Never publish arbitrary CLI strings, partial artifacts, IDs or billing guesses.
Test an actual adapter invocation with its local double. Use no real account or model.

## Design

Share the ordinary error vocabulary. In Messages mode use the typed terminal subtype first,
then a single recognized error signature. Unknown, conflicting or malformed evidence keeps
its existing fallback. The durable failure mapper may add only an exact approved cause to
an established diagnostic phase. Retain the previous format for ordinary reviews.
