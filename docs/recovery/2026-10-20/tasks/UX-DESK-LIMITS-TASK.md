# Правка предложенных пределов до разрешения

На третьем экране короткого мастера коллега видит резерв и предел действий.
Нужно изменить предел для этого же запуска без поиска задачи и переписывания
рекомендации. Нулевое значение должно иметь понятную обратную связь. При изменении
не выдавать разрешение. После просмотра поправки и явного подтверждения в журнал
должны попасть только фактически показанные значения. Вернуть пользователя
из редактора в тот же запуск Desk. Проверить обе локали и ширину 375 px.
