# Windows: проверка приватности файла подписки

База `bd393c43`. Job `133230695977`, Windows Server 2025/Python 3.11,
отказал в первой позитивной проверке каталога до выдачи постороннего права чтения.
Записанный traceback указывает на проверку родителя или домашнего каталога.
Журнал не содержит их SID и DACL. Прежний тест задал только DACL родителя.

Задать и независимо перечитать владельца и права временных каталогов и файла.
Доказать, что на фактически приватном дереве проходит обычная проверка, а после
выдачи Builtin Users права чтения ровно одного файла та же проверка отвергает файл.
Проверить на имеющихся Windows Python 3.11 и 3.12 и обеих кодировках.

не участвуют. Производственное решение о доступе должно остаться строгим.
