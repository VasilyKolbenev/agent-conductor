# H5-SUB-R5-I2B-CLOSE: ограниченное завершение перед B

Основание: решения Codex от 26.10.2026 в `H5-SUB-R5-I2B-DECISION-REPORT.md`.
Задание действует после коммита этих документов. Не прерывать и не переписывать текущий I3.
Ведущий Opus; небольшой diff Sonnet; не начинать новый общий аудит I2b.

## 1. Последовательность и исключения

1. Сохранить и проверить текущую итерацию I3 по `758a159`; f1/f2/f5 остаются в ней.
2. Применить Q13 и Q11 ниже на сохранённой базе, отдельно от живого исполнителя I3.
3. Собрать проверенный wheel из окончательного кода и подготовить защищённую установку Р7/Р8.
4. Провести один ограниченный A2; заполнить run-ready/preflight и отчёт подготовки B.
5. Только затем попросить владельца о свежем входе Claude и перейти к B по существующему runbook.

Не входит: Codex A-I1, новый relay для Grok/Kimi/DeepSeek, общий installer, новая архитектура
env, автоматическое восстановление lease, API-ключи, второй цикл, изменение модели или бюджета.
Q6 и Q8 применить к локальным доказательствам/точной конфигурации B согласно DECISION-REPORT.
TASK I3 не переписывать задним числом; этот дополнительный TASK явно разрешает Q11/Q13.

## 2. Q13: правдивый закрытый отказ checker

Варианты: сохранить marker_standing для обоих отказов (отклонён: сообщает несуществующий факт)
или новый claim_refused для отсутствующего marker (выбран). Retry и владение не меняются.

Названные файлы: `src/conductor/command/adapters/independent_transport.py`,
`src/conductor/command/adapters/independent_check.py`, `src/conductor/command/verify_road.py`,
`src/conductor/command/verify_holds.py`, существующие тесты закрытых причин и
`tests/test_relay_road_refusals.py`. Общие документы обновляет ведущий после кода.

- NotStarted("claim") → error/claim_refused, текст о невозможности зарезервировать проверку.
- NotStarted("claim_standing") → error/marker_standing. Нечитаемый marker не считается пустым.
- Проверить отсутствие task spawn, чистую lease при доказанном отказе и неизменную защиту от
  повтора при marker. Не менять итог на verified и не добавлять автоматического retry.
- Красная фаза на реальном сравнении нового reason, зелёная в обеих кодировках; мутант,
  который снова смешивает две причины, должен быть красным. Closed-set guard обновить вместе.

## 3. Q11: предусловие теста удержания login

Названный файл: `tests/test_login_ownership.py`. Product code не менять.
Сохранить два реальных проекта и второй процесс: они доказывают межпроцессную lease.
Установить явный setup handshake и освобождение по сигналу родителя в finally.
Допустимые setup/watchdog пределы и основание — DECISION-REPORT Q11.

Не менять смысл проверок ради зелёного. В отчёте отдельно: достигнуто предусловие, отказ
второго до снятия удержания, отсутствие его spawn, успешный второй после освобождения.
Setup failure / ошибка worker остаются failed, со своим именем; не skip/retry.
Контроль преждевременного освобождения lease должен опровергать тест; не требовать искусственно
замедлять ОС на 8 секунд или заново искать причину всех задержек Windows.

Q11/Q13 проверить адресно в обеих кодировках. Итоговый полный набор провести на окончательном
коммите в чистом detached worktree по стандарту; не дублировать одинаковые полные прогоны
до и после этих двух заранее известных правок без причины.

## 4. Р7/Р8: подготовка окружения B

Вне репозитория: защищённый `DecemberCommand\product\<sha>`, manifest и preflight, которые
проверяют целиком исполняемый код и фактический базовый Python. Изменяемый `$KIT` не является
основанием доверия. Установка из wheel, не editable; источник репозитория не подмешивается
через PYTHONPATH/user-site/изменяемый cwd. Защищённый scratch для операций вне boundary.
Обычный scratch каждой задачи уже назначается confined_spec; не менять это поведение.

В отчёте назвать code SHA, wheel SHA256, источник wheel, пути/ACL/manifest и результаты.
Локальный wheel B не объявлять финальным CI-кандидатом R5. Последний требует зелёной матрицы
на точном SHA и wheel того run. Не читать настоящие credentials ради упаковки/ACL.

## 5. D13 A2: только native launch/lifecycle

Использовать существующий native relay fixture и функции построения окружения/spec;
не переписывать их логику. Один отдельный native-файл и его CAPPED запись, либо именованное
расширение существующего `tests/test_relay_home_native.py`, если укладывается в лимиты.
При недоступности точного protected CLI явно показать невыполненное предусловие;
обычные CI не должны требовать установленного личного Claude. Локальный обязательный A2
с пропуском не считается пройденным. Harness invocation — только:

```text
<protected Claude Code 2.1.239>/claude.exe --version
```

Без -p, prompt, stdin и настоящего login-home. Синтетический home правильной формы в
изолированном test-root, реальный login guard, relay mint/copy-in/discard, настоящий
ProcessRunner и AppContainer. Не менять глобальный HOME и не использовать вход владельца.
Два режима boundary: dispatch и review; checker повторно не запускать — он использует review.
UTF-8 и cp1251, по одному native-файлу в процессе, последовательно: максимум четыре CLI spawn,
timeout каждого 60 с. Платных запросов и попыток inference — ноль. Повторов ради зелёного нет.

Обязательные наблюдения:

- Процесс завершён, exit 0, stdout действительно содержит ожидаемую версию 2.1.239.
- CommandSpec содержит настоящий boundary; переданный CLAUDE_CONFIG_DIR — новый relay,
  TEMP/TMP/LOCALAPPDATA — runtime попытки. Проверка spec не доказывает, что CLI читал credentials.
- Исходный синтетический вход неизменен; relay удалён; временные разрешения/профиль сняты.
- active_tokens() пуст; project owner и login lease повторно берутся обычным способом.
- Отдельные наблюдения не объединять в ложный successful action/verdict.

Наблюдения A2 не включают успешную подписку, no-refresh на inference, prompt/model/checker или
публичную transport road. Это первый B. В отчёте сохранить данное ограничение.
При timeout/unknown/нечистом retirement — остановка, запись факта и существующее восстановление;
не чистить lease вручную и не запускать B поверх неопределённости.
Если для этого smoke требуется новая архитектура — не расширять задачу; вернуть конкретное
препятствие Codex. A1, сетевую лабораторию и новые сторонние инструменты не начинать.
