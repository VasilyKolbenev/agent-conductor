# Контракт описи

У существующей `verify` остаётся машинный отчёт с абсолютными путями. Отдельная
команда `manifest ROOT` получает содержимое в контексте `verified_bundle`, который
проверяет состав, закреплённые хеши и обычные файлы под удержанием. В ответ входят
объект `manifest` и его `sha256`. Формат байтов для хеша — канонический JSON
проекта в UTF-8. Относительные пути в объекте используют разделитель `/`.
Хранение отдельного имени digest в `verify` связало бы формат старых потребителей
с новым артефактом.

Проверки через CLI сверят явные относительные пути и отпечаток двух независимо
размещённых копий. Замена одного байта должна завершить команду без описи. На
реальных исходниках сверить опубликованные хеши и собрать артефакт в чистой папке.
Отпечаток характеризует байты и раскладку. Защита родительского каталога,
проверка издателя и условий распространения, работоспособность shell и разрешение
на реальную роль остаются отдельными условиями.
