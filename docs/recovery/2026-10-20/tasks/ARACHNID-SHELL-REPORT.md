# Корневой экран Arachnid

Корень установленного продукта открывает Arachnid с реальными сессиями проекта.
В архиве `dalio-patch` выбор Do на орбите показывает diff двух файлов, результат
семи тестов и вердикт независимого Codex. Архив открыт по обычному URL без фрагмента.

- [Принятый запуск](http://127.0.0.1:7828/) — корень копии проекта в режиме просмотра.
  Слева сразу выбрана сессия принятого запуска, в центре остаётся Атлас. Выберите

- Ссылки с явно указанным `#screen` сохраняют назначение прежнего управляющего
  экрана. Из Arachnid та же поверхность открывается кнопкой «Управление процессами»
  по `/panel/studio.html`. Desk продолжает проводить подготовку реальной задачи.
  Новый адрес конкретного запуска имеет вид `/#session=dalio-patch`.

## Ревью Codex

На исходном пакете воспроизведены два падения новых сценариев входа: корень открывал
старый редактор. Дополнительные проверки поймали совпадающие адреса двух новых
черновиков, повторный вывод заголовка под именем пользователя, применение чужого
ответа и сохранение текста предыдущего архива при смене владельца того же порта.
Исправления проверены через настоящие локальные серверы. У зарегистрированного
проекта сверяется принадлежность. Если связь с архивом без идентификатора пропала,
повторное подключение начинает новую локальную сессию и очищает несохранённый текст.

Новые сценарии Chromium проверяют пустой проект, несколько локальных сессий, сохранение
черновика внутри вкладки, выбранную попытку, запоздалый ответ, недоступный адрес,
чужой проект, начальное открытие потока, переподключение, видимость реальной утилиты,
мобильный фокус и возврат из редактора. Три контролируемые поломки в сцене дали
ожидаемые падения. Состояние личной V2-памяти и живой dispatch ведущего харнесса
остаются отдельными задачами. Здесь Атлас отвечает локально по записям сессии.

Рабочие материалы этой проверки на ноутбуке находятся в
`Documents/Codex/work/arachnid-shell-1109`. Там сохранены изображения
`arachnid-root.png`, `arachnid-do.png` и `arachnid-narrow.png`. При новом старте
используйте Python из `4f30759/env`, `studio-serve.py` и те же каталоги примеров
`../studio-action-1109/accepted-dalio` (view, 7828) и
`../studio-action-1109/utility-project` (active, 7829).

После штатной остановки демо эти строки снова откроют принятый запуск. Для второго
проекта используйте последнее действие в отдельном окне PowerShell, задав там те
же три переменные.

```powershell
$kit = Join-Path $env:USERPROFILE 'Documents\Codex\work\arachnid-shell-1109'
$projects = Join-Path $env:USERPROFILE 'Documents\Codex\work\studio-action-1109'
$python = Join-Path $kit '4f30759\env\Scripts\python.exe'
& $python -I -B -X utf8 "$kit\studio-serve.py" view "$projects\accepted-dalio" 7828
& $python -I -B -X utf8 "$kit\studio-serve.py" active "$projects\utility-project" 7829
```
