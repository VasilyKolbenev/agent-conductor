# Учёт двух действий Studio в карте переноса Desk

Восстановить строгий учёт обработчиков в `tests/test_desk_function_map.py` на базе
`4120c38`. Studio добавила два действия в демо для коллеги. При открытии формы требуется
указать работающий вход Desk; при открытии учебной приёмки — кто отвечает за перенос.
Обе кнопки Studio, Desk и данные запуска остаются в прежней версии.

Приёмка: полный список из boot и spread проверяется по именам и без дублей. Ошибочная
классификация, смена владельца долга или появление неизвестного обработчика обнаруживаются.
Проверить карту в двух кодировках и существующий браузерный путь к форме Desk.
