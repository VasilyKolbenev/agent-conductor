# Штатный --prompt до подключения аккаунта

Одна последовательная пара на 0.38.0, настоящем ProcessRunner и AppContainer без internet capability. A — read-only home K2b.1 и отдельный штатный runtime scratch. B — отдельный синтетический state home в writable scratch с защищёнными от записи config и credential, в том числе сам каталог credentials; иначе условия те же. В обоих случаях токен поддельный, нет refresh, реальные login-home и аккаунты не открываются. Разрешена только известная команда --prompt; модельный запрос до реального сервера запрещён.

Сравнить фазу остановки, классы диагностик и имена созданных объектов без значений токенов/сырого ответа. По закреплённому исходнику run-prompt.ts создаёт session до runPromptTurn. Ошибка записи/создания, отличная от ошибки этапа provider, может разделить причины. Одного exit code или отсутствия сетевого ответа недостаточно. Если сигнал не различает, так и записать. Не расширять права исходного credential и не включать продуктовый dispatch. Дать конкретную передачу W3 поверх уже проверенных stage, готовности и нативного loan.
