# Подключение участника из черновика Desk

**Итог.** Коллега может открыть инструкции по подписке в соседней вкладке, настроить участника и вернуться к прежней задаче. На чистом wheel Chromium дошёл до предпросмотра с сохранёнными целью, материалом и выбором рабочей папки.

## Реальный путь

- В новом проекте реестр пуст. Desk объясняет, где запустить `conduct providers --dir .`, и открывает существующий экран «Участники» в соседней вкладке. Исходная вкладка сохраняет задачу.
- Кнопка «Проверить участников» читает реестр именно этого проекта. Пока сервер прежний, чтение черновика возвращает HTTP 200 и сохраняет его ключ. После остановки и запуска второго учебного сервера на том же порту прежний черновик возвращает HTTP 404. Открытая вкладка сохраняет ответы в новом экземпляре, обозначает незавершённое сохранение и затем показывает команду. После обновления страницы остаются та же цель, те же материалы и пустая рабочая папка.
- Второй сервер сообщает о двух учебных участниках, `claude-code` и `codex`, с `auth=subscription` и `task_road=boundary`. После подготовки задачи последняя операция в журнале браузера — `automation/preview`. Разрешение и выполнение остаются за владельцем.
- В отдельном сценарии ответ HTTP 503 оставляет состав неизвестным и даёт повторить чтение. Если проект после этого сообщает о пригодной команде с API-доступом, коллега может продолжить прежним способом. Подключение подписки остаётся доступным отдельно.

## Проверка

- Установили wheel из `1c7023d` в отдельное чистое окружение, проверили путь импорта из `site-packages`. SHA-256 файла — `0ed205d3a15a047ee27b75ef732cb3f5962c7b8f05cf8fadd10a125ff9df1674`. В этом окружении прошли все три браузерных сценария. Основной маршрут проверили на русском при ширине 375 пикселей в тёмной теме и на английском при 1280 в светлой.
- Регрессия из исходников — 124 проверки в UTF-8, 124 в CP1251 и 40 браузерных проверок. Для общего теста окончаний файлов взята однострочная правка уже принятого отчёта `13972e2`.
- В отдельной копии три контрольные проверки прошли. Шесть независимых подмен выявлены: другая страница инструкций, чтение Git вместо реестра, потеря черновика при HTTP 404, ложное сообщение о сохранении, обязательное подключение подписки при готовой альтернативе и ссылка цвета панели. Для последней подмены контракт проверяет фактический контраст CSS.
- Снимки интерфейса, извлечённые с экранов строки и журнал HTTP сохранены локально в `.pytest_cache/participant-final-proof/`. Итог установки — `.pytest_cache/connect-installed-verification.log`, результаты подмен — `.pytest_cache/connect-mutations/results.json`.
