# Запуск зарегистрированного двойника в браузерном Do

Оба официальных Windows-наблюдения остановились после записи аренды эффекта и до первого version probe. В журнале CodeIntegrity события 3077/3033 называют разные неподписанные тестовые `codex.exe` в точных каталогах этих двух случаев. Целевой тест находится вне дерева `tests/`, в котором уже подключена штатная проверяемая подстановка только для зарегистрированных двойников.

Подключить существующую тестовую подстановку к этому браузерному сценарию и доказать, что изменённый зарегистрированный файл отклоняется до запуска. Проверить по публичному пути Desk/Studio, что одна разрешённая работа изменяет учебную копию, независимый проверяющий получает фактическое содержимое и владелец может принять результат. Не менять Windows Code Integrity, продуктовые аренды, лимиты и запуск настоящих нативных CLI. Сохранить оба исходных артефакта.
