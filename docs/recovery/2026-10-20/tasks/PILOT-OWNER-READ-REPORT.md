## Причина и изменение

Studio скрывает кнопки при неподтверждённом владельце. Если чтение открытой вкладки попадало
в интервал подмены, она продолжала показывать последнее прочитанное состояние. Возврат поля
Python тестовой фикстурой не посылает в браузер событие. Реальный владелец фиксирует
неопределённость до восстановления. Сам сценарий уже требовал повторного чтения в своей
второй половине.

Сценарий теперь добивается этого порядка настоящими GET по кнопке обновления. Во время
неопределённости он видит restart_required по HTTP и в DOM, кнопки pause нет. После
восстановления видит waiting с подтверждённым владельцем, pause снова доступна. Журнал
до нажатия совпадает с журналом исходной выдачи разрешения. Вторая половина проверяет
неизменность истории паузы и наличие resume после следующего восстановления.
Публичный HTTP и Chromium настоящие, адаптер локальный, исполнений ноль.
