# Optional model ID per Desk role

Carry a full model ID explicitly typed by the owner to the existing
`participants[].model` contract. An empty field leaves the harness default.
Expose one optional `model_pin_supported` fact on the existing workflows
roster from the registered adapter profile. Unknown and default-only
providers are distinct. Do not guess a list or claim account availability.

The alternative of showing a field for every harness would promise a choice
Grok Build's reviewed profile cannot forward. For a new run reject a pin
when its registered profile definitively has no model flag. Keep the frozen
config and idempotent replay of existing runs. In Desk bind the pin to both
role and selected provider. Clear it on provider change, restore editable
answers only inside their task tab, and show the pinned ID from the frozen
run before grant. Changing an already-prepared request cannot authorize the
previous preview. Existing Studio and the dispatch-time refusal stay in force.

One served focused journey: Codex checker with a user-supplied full ID,
Grok role with its default, refresh and back. Check API shape, early refusal,
replay and the final grant card without any provider call.
