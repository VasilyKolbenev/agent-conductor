# Один разрешённый Do с патчем

Добавить явный профиль dispatch в опубликованный план, доступный для Codex по подписке.
Один grant, одна аренда действия и один срок. Codex готовит текст патча в read-only;
применение не обращается к модели. В Studio и Desk до разрешения видны оба этапа.
Непомеченные планы читаются и исполняются как раньше. Требуется отдельный проверяющий.

Проверить на обычном входе приложения с заменой внешних CLI фиксированными ответами.
Проверяющий должен получить байты результата с диска. Негодный ответ, чужой путь, ссылка,
дрейф, превышение времени, потерянный результат и повтор не дают ложного успеха.
Живого вызова модели, защищённой установки, публикации и приёмки владельца в задаче нет.
