# Показать файлы результата перед приёмкой

В чистой репетиции Далио с Git source получены два действительно изменённых файла.
При переходе «Открыть результат» коллеге видна папка work и имя проверяющего.
Показать в той же карточке, что изменилось относительно исходника к моменту проверки.

Использовать связанный с evidence неизменяемый снимок. Не обходить сегодняшнюю папку
задачи или Git. Исторические запуски без снимка читаются в прежнем виде. Повреждение
снимка не превращает текущие файлы в доказательство и не блокирует чтение журнала.

Выбран дополнительный ограниченный блок чтения запуска. На последнем подтверждённом
patch Do перечитывается только хешированный список файлов, без blob и содержимого.
Вариант с новым URL и вводом пути из браузера здесь не нужен. Проверить последний
результат, попытку, участника, отдельный checker и ссылку на evidence. Если снимок
перечисляет много изменений, показать первые имена и полный счётчик. Контракт записи,
приёмка и полномочия прежние. Проверить на чистом HTTP-чтении, подмене рабочей копии,
повреждении снимка, в Chromium и в двух языках. Срез следует за замороженным кандидатом
живого прогона.
