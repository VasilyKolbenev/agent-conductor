# Проверки сохранения черновика решения

На `4120c38` полный прогноз UI выявил четыре красных сценария двух причин.
DOM-двойник теста локализации не читает раскрытые панели. Два теста принятия
решений привязывают требования к написанию редьюсера и обработчика вместо работы
разрешённых действий. Заменить устаревшие ожидания доказательствами поведения.
Проверить русский и английский, сохранение пользовательских полей и выбранной панели,
сброс после подтверждения, отказа сервера и смены запуска. Сохранить проверки
независимости черновика шага. Граница тестов — внешний транспорт, реальное состояние
проекции. Изменение приложения требуется только при воспроизведённом дефекте.
