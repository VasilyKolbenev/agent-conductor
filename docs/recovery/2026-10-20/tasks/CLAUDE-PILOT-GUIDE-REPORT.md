# Ручная передача в Claude Code в первом проекте

Итог: в RU и EN описан проверенный ручной обмен через официальный CLI владельца.
TASK `dd06b85c` и уточнение `1cf26cf6`, руководства `8ab4f0f9`, карточки `607103b0`,
база `305003d8`. Статус: проверено локально.

## Что получает коллега

В активной Studio коллега открывает «Своя утилита», выбирает «Вручную» и переносит
текст задачи в свой Claude Code. В проект возвращается предоставленный коллегой ответ
с подписью «Ответ записал оператор». Для личного входа даны ссылки на документацию
Anthropic и поддерживаемые регионы. Публичная автономная роль остаётся открытым пунктом.
Руководства сохранили инструкции подключения Codex и Grok и ссылку на исторический Goal.

## Проверка

- На установленном Windows wheel из `305003d8` с SHA-256
  `29364c44bf6a7c88ecb3d6c98737b3e36d1eae90576221f7a014aec6ac057d20` совпали 554 файла.
  В Chrome на пустом проекте и реестре провайдеров прошли регистрация, копирование задачи
  и сохранение учебного ответа. После обновления страницы сохранились исходный текст,
  ответ и метка оператора. Было три записи (`attach`, `send`, `manual_reply`), ноль
  запусков и внешних запросов. Буфер браузера в этой проверке находился в памяти.
- Два новых сценария дали 2 failed в красной фазе на примерах с `CLAUDE_CONFIG_DIR`.
  В зелёной фазе `test_docs_commands`, `test_boot_claims` и `test_file_endings`
  дали по 59 passed в UTF-8 и CP1251. Проверены обе локали и названия кнопок из Studio.
- Отдельная проверка ссылок в Chromium до правки дала 2 failed: обе локали открывали
  `245e8f04`. После правки в полном модуле карточек проверены имена ссылок, полные адреса
  и якоря раздела установки у Codex и Grok. Модуль и три проверки руководств вместе
  дали по 71 passed в обеих кодировках, структурные ограничения ещё по 331 passed.

## Мутанты

В копиях страниц проверены четыре независимые подстановки в каждой локали: пустая
страница, включение Claude в общий абзац мастера, инструкция с `CLAUDE_CONFIG_DIR`,
замена подписи оператора утверждением о независимой проверке. Каждый вариант дал
ожидаемую ошибку. Контрольные тексты после каждой подстановки проходили, SHA-256
обоих исходных руководств сохранился.

В отдельной копии браузерный тест без изменений дал 2 passed. Замена ссылки обычным
текстом дала 2 failed. Неверный якорь только у Grok дал 2 failed после успешной проверки
Codex. В обоих случаях возврат файла подтверждён исходным SHA-256.
