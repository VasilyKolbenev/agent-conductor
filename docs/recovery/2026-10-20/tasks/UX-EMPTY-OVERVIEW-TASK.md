# Первый экран пустого проекта

На пустом проекте коллега видит один основной переход к своей задаче рядом с вопросом
о результате. Проверить и убрать пустой выбор задач и повторяющиеся призывы с этой страницы.
Оставить создание записи без запуска доступным, состояние отказа читаемым, клавиатурный
переход и остальные экраны работающими. Людей с уже существующей работой и учебный пример
продолжают вести фактические данные. Измерить результат на 375 и 1280 px в обеих темах.
