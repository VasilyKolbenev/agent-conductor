# W4. Доступ AppContainer к исходному файлу Kimi

База `f9f90b6`. Источник — H5-KIMI-SUB-TASK и W4 независимого ревью K2a.
Проверить, откажет ли реальный Windows runner до выдачи прав на relay одного harness, когда
вложенный файл другого, настроенного Kimi, имеет собственное разрешение на чтение контейнерам.
Создать только фиктивный Windows-профиль под тестом. Байты credential не читать.

Сначала зафиксировать проверяемый дизайн, затем снять RED на границе runner. Зафиксировать
проверяемое наличие и тип ACE, закрытые родительские DACL, неизменность исходного объекта.
Проверка права открытия файла не должна публиковать содержимое. Ветку исполнения Kimi ведёт
отдельная задача. Решение об изменении контракта runner принимает техлид после ревью.
