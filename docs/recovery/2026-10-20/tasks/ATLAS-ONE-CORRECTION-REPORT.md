# Одна доработка после замечания проверяющего

Итог. В локальном кандидате `7868522` оператор до разрешения может выбрать одну
доработку Do. Свидетель для пути `implement-patch-v1` находится в `db80eb5`.
Публичный пилот `7f6b825` продолжает использовать прежнюю версию Studio.

## Опыт оператора

Без выбора в предпросмотре пять действий, одна попытка Do и 3600 секунд общего
резерва. Если выбрать доработку, появятся шесть действий и 4800 секунд. Бюджет
второй попытки включает 600 секунд на работу и 600 на проверку. Срок разрешения
остаётся 7200 секунд. Остальные шаги допускают по одной попытке.

Выбор фиксируется при сохранении черновика процесса. Перезагрузка восстанавливает
его условия. Создание предпросмотра само по себе не запускает исполнителя.
При одновременном выборе разных условий сохраняется одна ревизия. Если опубликованные
условия успели измениться, подготовка завершается до создания задачи.

## Доказательства

- До реализации тесты опции и условий зафиксировали отсутствие нужного поведения.
  В Chromium с HTTP-сервером проверены выбор, просмотр, перезагрузка до разрешения
  и открытие уже разрешённого плана. В транзакционном тесте две подготовки дождались
  друг друга у записи пустого черновика. Подмена просмотренного бюджета отказала.
  По 497 профильных проверок прошли в UTF-8 и CP1251. Проверены пять целевых мутаций.
- Тест раннера действительно применил две правки к учебному каталогу под одним разрешением.
  Первый unittest вернул ошибку. Независимый тестовый проверяющий прочитал протокол
  и вернул замечание с файлом и строкой. Второй исполнитель получил замечание и файлы
  первой попытки, изменил только реализацию. Повторный unittest прошёл. Проверяющий
  получил накопленную правку с обоими файлами и отдельный протокол второй попытки.
  По 340 профильных проверок прошли в обеих кодировках. Удаление протокола теста,
  замечания либо неизменённого тестового файла из накопленного результата обнаружены.
- Из чистого `git archive 7868522` собран wheel с Hatchling 1.32.4. Установка
  в новый venv выполнена без сети. 547 файлов пакета совпали между исходниками, wheel
  и установкой. Штатная команда помощи отработала. SHA-256 этой локальной сборки
  `b6b978ade9c77880dd3a533c50a7978cee84d614a4b1d6afced1e4aa3f9bb8bf`.

Проверки выполнены на Windows с двойниками внешних исполнителей. В живом чате
запуск unittest требует закреплённого плана тестов. Новый переключатель сам такой
план не создаёт. Следующие проверки — CI финальной сборки и одобренное прохождение
двух попыток на подписках с просмотром замечания, diff и протокола обеих попыток.
