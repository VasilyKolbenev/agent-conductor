# Имя в заголовке чата Studio

По решению владельца от 14 ноября у иконки ведущего в чате должно стоять
только имя: «Колосс» для русского интерфейса и «Colossus» для английского.
Область правки — строка заголовка и её начальное значение в HTML.

Проверить точный текст в Chromium на страницах новой и сохранённой сессии.
Ключ заголовка отделить от подписи автора в инспекторе, у которой другая роль.
