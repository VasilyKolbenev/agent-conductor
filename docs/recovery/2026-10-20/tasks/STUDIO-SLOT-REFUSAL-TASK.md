# Studio bounded-run refusal

When authorization returns `slot_busy`, show the reason beside the button and
offer a link to the holding run when the response identifies it. The owner can
inspect or pause it there. Keep the original form open, and never retry a write
or pause another run automatically. A missing holder must still explain the
conflict. An expired preview must prompt the owner to review the limits again.

Check these cases through the served Studio with a deterministic adapter. No
provider account, live inference, deployment or change to the single-run policy.
