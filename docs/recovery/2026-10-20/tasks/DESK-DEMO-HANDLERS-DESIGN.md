# Где живут две команды

`showTaskForm` открывает ввод новой задачи. В Desk это уже делает кнопка `#deskNewTask`
через `createWizardHost` и его `openNew`. Строка карты будет `host` c привязкой
к существующей подписке на click. Действие закрыто той же частью Desk, которая ведёт
мастер задачи.

`openDemoReview` создаёт учебный запуск `demo-counter-review` в режиме `confirm`
и ведёт из выбранной задачи на экран решений. Такого запуска из Desk пока нет.
Ответственный за перенос — D1, у которого в карте уже находятся демо-контекст
проекта и ручное открытие запусков. Это запись долга; наличие обычной карточки
решения или мастера ограниченного запуска само по себе этот путь не обеспечивает.

Проверить работающий вход мастера и отсутствие демо-маршрута в графе загруженных
Desk-модулей. Сохранить общий контроль полноты, закрытый словарь retired/pending
и отдельный тест чужого имени. Файл продукта менять не требуется.
