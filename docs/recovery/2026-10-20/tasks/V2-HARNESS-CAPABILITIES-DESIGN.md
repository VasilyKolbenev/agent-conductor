# Проверяемая возможность внешней утилиты

При выборе проектной утилиты Studio использует режим подключения и сохранённые обмены.
При ручной записи указывать источник (оператор), при ответе из моста — факт обмена
по arachnid.utility.v1. Учитывать случаи пустого списка, ожидания и неизвестного исхода.
Явно показать доступность ролей цикла и телеметрии для пользовательской утилиты.

Текст находится в существующей карточке. Новый каталог моделей или регистрационная
форма с предположениями по имени здесь не нужны. Проверить через действительный UI
и выданные рабочие материалы на русском и английском, включая отсутствие доказательства.
Отзывы поставщиков и форматы CLI отдельно соотнести с контрактом текстового обмена.
Публикуемый пилот использует точные байты 7f6b825; новая правка относится к будущей сборке.
