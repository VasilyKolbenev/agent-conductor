# Заголовок чата Studio

В текущей Studio рядом с иконкой ведущего отображается «Колосс» по-русски
и «Colossus» по-английски. База `9905a65`, задание `3c03085`, правка `2ca9122`.
Ключ заголовка отделён от подписи автора в инспекторе.

## Проверка 16 ноября 2026

- До правки две проверки точного текста упали на прежних подписях.
- В Windows Chromium все шесть браузерных сценариев входа прошли. В отдельной
  вкладке проверены начальный английский HTML, русский заголовок, переключение
  на английский, перезагрузка и возврат на русский.
- Из 40 смежных проверок сначала прошли 34, пять HTTP-проверок не смогли
  открыть локальный сокет в песочнице (WinError 10013), одна пропустила сборку
  wheel из-за отсутствия hatchling в тестовом venv. С доступом к loopback прошли
  39, последняя прошла отдельно со штатным окружением сборки.
- В изолированной копии неправильное английское написание и возвращённая
  русская подпись пойманы соответствующим браузерным тестом. В каждом случае
  один тест упал и один прошёл. После восстановления прошли оба.

Ревью Codex подтвердило границу изменения. Проверки выполнены локально, без
вызовов моделей. Опубликованный Windows Pilot 2 собран из `68dcb62`.
