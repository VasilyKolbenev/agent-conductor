# Предложение подписочного харнесса для общего черновика

Использовать существующий ограниченный запуск review: один участник, одна попытка, пустая
рабочая папка, самостоятельные предпросмотр и разрешение. Другой вариант — специальный
endpoint для прямого вызова CLI — потребовал бы второй механизм полномочий и восстановления.
Бюджет главной задачи расходуется отдельно.

1. В локальном мастере по явному запросу показываются доступные подписочные участники и текст,
   который получит выбранный участник. Подготовка создаёт обычные проектные записи, но не
   запускает работу. Имя исполнителя, параметры модели и пределы подписки видны до согласия.
2. Отдельная кнопка подтверждает только показанный запрос. Идентичный запрос имеет стабильную
   идентичность. При потере ответа сначала читаем журнал. Квоту, вывод участника, маршрут и
   готовность результатов определяет продукт.
3. Выход review — ограниченное структурированное предложение по уточнению задачи. В черновик
   попадает только проверенный текст подсказки после выбора пользователя. Исходная цель,
   разрешение, решения и управление процессом не берутся из ответа модели. Если в форме уже
   другая задача или изменился вопрос, старое предложение её не перезаписывает.
4. Доказательства: браузер с настоящим локальным сервером и фиксированным адаптером; отдельно
   отказ неизвестной структуры, подмена ревизии, повтор и отсутствие действий до разрешения.
   Проверка интерфейса не расходует подписку.
