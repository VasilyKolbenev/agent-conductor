# Конфигурация роли Read в изолированной попытке

Подготовить конфигурацию внутри существующего `ProcessRunner.container_profile`
для review с отключённой сетью, staged login и `kimi_state`. В предпросмотре
локального свидетельства получить отпечатки проверенного исходного профиля и
сгенерированных байтов. До передачи управления создать только config.toml,
выдать ему SID попытки чтение, удерживать файл и записать отпечатки вместе 
с identity в существующую ACL-опись. Закрытый список инструментов — Read.

Красные случаи: изменившийся исходный профиль, иной набор инструментов, чужой
файл назначения, попытка изменить конфигурацию/credential из AppContainer.
Проверить штатный session/new реальным CLI на фиктивном входе. Не переносить
секреты этим кодом: подготовка access-only credential и выдача полномочий
на подписочную задачу остаются отдельными задачами.
