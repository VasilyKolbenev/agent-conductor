## 1. Дефект

Run без гранта, чей план закончился любым словом (`complete` или `stalled`), читается
`unconfigured/authorization_required`. Причина — порядок в `_state`
(`src/conductor/command/policy_view.py`): `if grant is None` (строка 46) стоит раньше проверки
окончания (строки 51–52). Следствия, как они описаны в дизайне R1.2c:

- Studio рисует форму границ законченному запуску (`studio-automation.js:151`: форма при любом
  чтении без `authorization`), preview отвечает 200, а authorize — 422 «completed run accepts no
  authorization history» (`authorization_history.py:164–165`). Человеку предлагают то, что дверь
  заведомо откажет.
- Для desk правило 20 (`desk-status.js:85`: `unconfigured` без записи очереди) читает такую
  строку «не начат»; не проверялось, достижимо ли это сочетание на настоящем запуске.

Дефект существовал и до R1.2c для `complete`; слот в нём не участвует. Codex 21.10: R1.2c его не
устранил, не считать исправленным, учитывать при приёмке.

Почему R1.2c его не трогал: модель Studio держит слово `unconfigured` за чтением без гранта
(`studio-automation-model.js:93–94`: при `authorization === null` принимается только
`state === "unconfigured"`, `control` и `expires_at` равны `null`). Перестановка только в
`policy_view.py` дала бы чтение, которое `projectAutomation` отбросит как неверное. Тест
`test_an_ended_plan_nothing_was_granted_to_still_reads_unconfigured` (`stalled`, `complete`)
закрепляет нынешнее чтение намеренно.

## 2. Ожидаемое поведение

1. Run без гранта и с закончившимся планом читается `complete/plan_ended`: то же слово и та же
   причина, что у законченного run с грантом; `authorization`, `control` и `expires_at` — `null`,
   счётчики нулевые, `owner_present` как есть.
2. Studio принимает такое чтение, показывает «План завершён» и **не рисует форму границ**,
   preview и authorize недоступны. Кнопок pause, resume и revoke по-прежнему нет.
3. Run без гранта с открытым планом по-прежнему читается `unconfigured/authorization_required`.
4. Двери не меняются: authorize и control отвечают 422 с тем же текстом, чтение ничего не пишет
   и не трогает слот. Новых слов и причин в `AUTOMATION_STATES` и `AUTOMATION_REASONS` нет
   (словарь V1 оставлен решением Codex, R1.2c-В2).
5. Строка desk такого run читается по правилам окончания, а не «не начат»; hub и очередь не
   опираются на `unconfigured` для законченного run.
