# Дистрибуция пилота из репозитория

Привязать Windows Pilot 1 к зелёному 7f6b825. На GitHub Releases подготовить ZIP,
его контрольную сумму, исходный wheel и краткую инструкцию. Открытие публичной ссылки
отделить от объявления полноценной альфы 2.0. Уточнение владельца определяет аудиторию.

В каталоге distribution/windows-pilot сохранить публичные входы для сборки ZIP.
Дистрибутив должен воспроизводиться из них и явно переданного CI-wheel с ожидаемым SHA.
Проверка включает точное сравнение архива, чистый экспорт через Git и отказ на иных байтах.
Код продукта и тег выпущенного кандидата остаются привязаны к исходному SHA.
