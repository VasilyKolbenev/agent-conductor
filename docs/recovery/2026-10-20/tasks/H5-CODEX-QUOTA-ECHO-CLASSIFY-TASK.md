# H5-CODEX-QUOTA-ECHO-CLASSIFY — определить класс совпавшего поля

Решение Codex, 28.10.2026. Одно новое различающее измерение; не повтор старого измерителя.

## Основание

Одно штатное чтение по H5-CODEX-QUOTA-LIVE-DIAG завершило version и app-server с exit 0.
RPC: 1403 байта, три ожидаемых ответа без error, stdin delivered, без усечения.
Но output_contains_env_value=true и _login_echo=true; именно это вызывает source_error.
Retained/residue отсутствуют, процессы завершены, login lease снят, проект closed.
Запись: `work/codex-first-product/quota-diagnostic-9788.json` под Documents/Codex,
SHA-256 `7828481a7609a8b17757d3289c88cd91b29dfe198f685c6e5f46b4a46f4a5c3a`.

Общий sampler считает секретами все строки объявленного login JSON длиной от 12 символов.
Измерение не записывало имя совпавшего поля, поэтому пока не различает токен и метаданные.
Называть срабатывание ложным или ослаблять защиту до различения нельзя.

## Измеритель и границы

- Основа — уже проверенный diagnose-quota.py. Новый исходник:
  `Documents/Codex/work/codex-first-product/classify-quota-echo.py`.
  Ведущий читает diff/offline результаты, фиксирует хеш, затем копирует в защищённый
  `%USERPROFILE%/DecemberCommand/h5-a/tools/classify-quota-echo.py`.
- Сохранить проверки точного product9788, manifest/импорта/CLI, closed/нет active или unknown
  действий, свободного порта 7802 и точной конфигурации. Один штатный read, максимум два
  ожидаемых процесса version/RPC, без изменения параметров, результата или исключения.
- Новый эксклюзивный маркер в защищённом h5-a. Старый маркер не трогать. Любой исход
  потребляет разрешённое измерение; автоматического повтора нет.
- Дополнительный observer на login_home._read_json делегирует оригинал ровно один раз.
  Он рассматривает уже прочитанный результат лишь для точного объявленного credential path
  и при действующем owner.leased_login(). Самостоятельных открытий auth-файла нет.
- В памяти сопоставить исходные строки по правилу штатного sampler (len(str) >= 12,
  затем UTF-8), их фиксированные имена полей закрытой схемы Codex и полученный stdout.
  Неизвестные имена обозначать только `unknown`. Значения и сами ключи неизвестных полей
  не сериализовать. Совпадение токена и metadata по значению сохраняет оба класса.
- Выход: только фиксированные source-field enums, фиксированные RPC-location enums
  и технические booleans/counts. Для неизвестного расположения — `other`.
  Запрещены значения, подстроки, длины отдельных секретов, хеши секретов и сырой stdout/stderr.
  JSON для сопоставления существует только в памяти, не меняет продуктовый parser.
- Наблюдатели восстановить в finally, samples очистить. Не менять защиту, parser, refresh,
  census, таймауты, вывод или настройки провайдера. Никаких моделей, login/logout, catalog.
