# Использовать редактор пределов Studio

В коротком Desk `guideTerms` показывает рекомендацию. Его карточка ожидает
рекомендованный ответ с бюджетом; ответ сервера для собственных пределов имеет
другую схему. Редактор Studio уже поддерживает индивидуальные времена, попытки,
отказ по сроку просмотра и подтверждение по новому digest. Используем этот путь.

Одна кнопка с третьего экрана ведёт в Studio того же сервера и того же запуска.
Состояние перехода текущей вкладки содержит только идентификаторы и предлагаемые
числа, полученные с карточки. Без содержимого задачи и без данных разрешения.
Редактор предъявляет те же числа и пустое поле подписи. Значения и известные шаги
проверяются для выбранного запуска. Для записи потребуются обычные новый
предпросмотр сервера и отдельная выдача разрешения. Сам переход его не создаёт.
Действие «Вернуться в Desk» открывает запуск, не возвращая устаревшую карточку
мастера. Обычное открытие Studio сохраняет прежнюю форму.

В Chromium снять отказ на исходной сборке, затем пройти редактор глазами коллеги:
сравнить автоусловия с полями, проверить ошибочный ноль, увидеть новые условия
после серверного просмотра, убедиться в отсутствии grant до нажатия и совпадении
записанного grant с принятыми условиями. Только учебные адаптеры.
