# Arachnid Studio

Arachnid Studio — локальная студия для разработчика, который поручает ИИ правку в коде,
и для того, кто решает, выпускать ли её. Опишите задачу Колоссу, выбранному вами ведущему агенту.
Согласуйте, кто найдёт причину, кто внесёт правку, кто её проверит и когда позвать вас.
Вернувшись, вы увидите изменения, протокол тестов и заключение проверяющего по одной попытке.

- [Разобрать готовый результат на GitHub](docs/run-example.ru.md) — проследить путь ошибки
  от диагноза до приёмки прямо в браузере, без установки.
- [Открыть Studio на своём компьютере](#запустить-arachnid) — посмотреть локальное демо
  без подписок.
- [Запустить свою задачу на Windows](docs/first-run-v1.md#1-установите-конкретную-сборку) —
  подготовить проект и подключить Codex и Grok по своим подпискам.

[English](README.md)

**Орбита принятого запуска Codex + Grok**

![Орбита в Arachnid Studio. Шаг Do выбран, справа открыты результаты этой попытки.](docs/assets/studio-orbit-ru.png)

В реальном запуске на Windows Grok изучил реализацию счётчика и тесты и нашёл, почему сбои попадали в число успешных запусков. Codex исправил `count_succeeded`. Три теста прошли, затем другой экземпляр Codex проверил правку. Оператор одобрил исполнение и принял результат. [Отчёт о запуске](https://github.com/VasilyKolbenev/agent-conductor/blob/3304810f645b0e515b95934328009f1456139c58/docs/recovery/2026-10-20/tasks/DALIO-FIRST-COMPLETE-REPORT.md).

## Запустить Arachnid

Для локального демо нужен **Python 3.11 или 3.12** с `venv` и `pip`.
Демо работает без входа в аккаунты и вызовов моделей. [Открыть страницу релиза][release].

| Windows | Linux (проверено на Ubuntu) | macOS |
| --- | --- | --- |
| ZIP с учебной реконструкцией цикла Codex + Grok. Свои задачи на Windows x64 можно запускать по личным подпискам. | Python-пакет с локальным примером проверки релиза. | Тот же Python-пакет и локальный пример. |

**Архив для Windows**

1. Скачайте [архив Studio][zip] и его [контрольную сумму SHA-256][checksum].
2. Сверьте контрольную сумму и выберите **Извлечь все**. Команда PowerShell есть
   в [инструкции к архиву][zip-guide]. Если Python ещё не установлен, скачайте с официального сайта
   [Python Install Manager][python] и в новом окне PowerShell выполните `pymanager install 3.12`.
3. Дважды щёлкните **`START.cmd`** в распакованной папке и оставьте окно открытым.
   При первом старте откроется учебная орбита. Выберите **Do** — справа увидите правку,
   три теста и заключение проверяющего. Для выхода нажмите Ctrl+C в окне запуска.
   Если открылась ранее сохранённая пара задач, вернитесь к примеру командой `.\START.cmd demo`.

**Дополнительно — память между задачами.** Закройте демо и введите `.\START.cmd new` в PowerShell
из папки приложения. Вы опишете две задачи, чтобы Колосс нашёл порядок проверок первой для второй.
Для работы агентов над вашей задачей откройте
[инструкцию по настройке проекта](docs/first-run-v1.md).

**Linux и macOS · знакомство со Studio.** Скачайте [Python-пакет wheel][wheel]. В папке со скачанным файлом выполните команды для Python 3.12. Если установлен Python 3.11, в первой строке используйте `python3.11`.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install --no-index ./agent_conductor-0.1.1-py3-none-any.whl
.venv/bin/conduct demo
```

В Windows тот же пакет позволяет открыть демо из PowerShell. Для Python 3.11 используйте `py -3.11` в первой строке.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index .\agent_conductor-0.1.1-py3-none-any.whl
.\.venv\Scripts\python.exe -m conductor demo
```

Откройте локальный адрес, который появится в терминале. Чтобы остановить демо, нажмите там Ctrl+C. Для своего проекта настройте поддерживаемые версии CLI, войдите в подписки и просмотрите условия запуска в Studio. [Первый реальный проект](docs/first-run-v1.md).

## Что видно во время работы

| Спросите Колосса или выберите шаг | Что откроет Studio |
| --- | --- |
| «Что Grok передал Codex?» | Диагноз и материалы запуска, на которые он опирается. |
| Выберите **Do**, затем попытку | Фактические изменения файлов, результаты тестов и вердикт независимого проверяющего по этой попытке. |
| «Что изменилось, пока меня не было?» | Последний записанный результат, решения, которые ждут вас, и ссылки на подтверждения. |
| «Найди порядок проверки из прошлой задачи» | Предложенный план и проверяющего со ссылкой на исходную принятую запись. |

По умолчанию команда проходит пять шагов Рэя Далио: ставит цель, выявляет проблемы, находит причину, составляет план и выполняет его. Можно собрать и опубликовать свой цикл. В боковой панели нажмите **Подключить харнесс**, затем назначьте роли в процессе. [Настройка цикла](docs/first-run-v1.md) · [Пример исходной записи о проверках](docs/assets/kolos-task-evidence.png).

| Харнесс | Что проверено |
| --- | --- |
| **Codex CLI + Grok Build** | Полный цикл из пяти шагов на Windows по подпискам владельца, без API-ключей. Исполнение и независимая проверка прошли в разных экземплярах Codex. |
| Claude Code | В изоляции по подписке выполнен Goal и сохранён результат. Identify остановился по таймауту. В инструкции описана ручная передача в официальный CLI. [Отчёт запуска](https://github.com/VasilyKolbenev/agent-conductor/blob/3304810f645b0e515b95934328009f1456139c58/docs/recovery/2026-10-20/tasks/H5-B-RUN2-REPORT.md). |
| Kimi Code CLI | Проверено открытие сессии в офлайн-тесте. Предстоит живая задача по подписке. |
| DeepSeek Harness | Адаптер с API-ключом прошёл локальные тесты. Сервис использует баланс API. |
| Своя CLI | Ручная передача или двусторонний обмен текстом через совместимый локальный мост. Автономная роль и работа по подписке зависят от адаптера. |

GitHub Copilot CLI и Cursor Agent можно добавить для ручной передачи задачи. [Как подключить свою утилиту](docs/first-run-v1.md).

Шаблоны карты проекта отличаются от стартовых процессов Studio:

- **`--template NAME`** пропускает вопросы `conduct init` и выбирает карту:
  - `default-orbit` — стандартная карта из пяти стадий.
  - `single-harness` — роль исполнителя и решение человека, без проверяющего.
  - `empty` — минимальная карта с заготовкой узла.
  - `minimal` — пример карты из протокола.

Начальная инструкция предлагает заменить узлы-заготовки реальными компонентами проекта;
если компоненты уже заданы, предлагает проверить их соответствие проекту.
`conduct init` не перезаписывает существующие данные. Активация владения описана в [первом запуске](docs/first-run-v1.md).
