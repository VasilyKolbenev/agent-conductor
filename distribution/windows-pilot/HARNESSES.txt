Для эксперимента запустите из распакованной папки:
    .\Start.cmd utilities
Откройте напечатанный адрес. Это отдельный пустой проект с сохранением обменов.
В просмотре примера Codex + Grok изменение настроек недоступно.

Что уже входит в wheel
• Codex CLI 0.164.0 и Grok Build 1.0.13 прошли общий цикл по подпискам на Windows.
  Grok читал материалы на Diagnose, Codex выполнял Do, другой Codex проверял результат.
• Claude Code 2.1.239 выполнил Goal по подписке в изоляции. Для проверки всей роли
  на новом аккаунте нужна отдельная живая приёмка.
• Kimi Code CLI 0.38.0 открыл тестовую сессию в изоляции. Живая задача по подписке
  в этой сборке ещё недоступна. Приложение Kimi Desktop и Kimi Code CLI различаются.
• DeepSeek Harness использует API-ключ и баланс API.
Studio сохраняет эти пять записей каталога. Подключение к реальной работе с личными
аккаунтами описано в инструкции именно к этой версии:
https://github.com/VasilyKolbenev/agent-conductor/blob/7f6b825/docs/first-run-v1.md

Как попробовать ручной режим за минуту
1. «Подключить харнесс» → «Своя утилита» → «Вручную». Введите, например,
   GitHub Copilot CLI и идентификатор copilot-cli. Нажмите «Подключить утилиту».
2. Введите «Учебный обмен», нажмите «Отправить задачу». Введите «Ответ оператора»
   в поле ответа и нажмите «Записать ответ». Обновите страницу: обмен сохранён.
   Для настоящей задачи пользователь сам передаёт текст своему CLI и возвращает ответ.

Автоматический обмен и пример без модели
В Studio выберите «Своя утилита» → «Мост совместимой CLI». Укажите имя
«Локальный эхо-пример» и идентификатор local-echo. Отправьте ему «Привет».
Оставьте окно с этим проектом открытым. Во втором PowerShell из папки пакета запустите:
    .\Start.cmd echo
Вставьте локальный адрес с портом из первого окна. Мост выполнит один обмен.
В Studio нажмите «Обновить обмены». Появится «Локальный пример получил: Привет».
Для выхода из Studio нажмите Ctrl+C в первом окне. Если Windows запросит подтверждение,
нажмите Y и Enter.

Мост ожидает одну строку JSON протокола arachnid.utility.v1 на запрос и ответ.
Обычный интерактивный CLI или собственный ACP поставщика требует отдельного
переводчика для автоматического обмена. Ручная карточка не назначает утилиту
исполнителем Do или независимым проверяющим и не считывает квоту подписки.
Проверка этого пакета выполнялась без запросов к поставщикам.
