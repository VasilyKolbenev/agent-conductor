Arachnid для Windows • Две ваши задачи

Вспомните завершённую задачу и её проверки. Для второй задачи Колос
предложит порядок, покажет, откуда взят каждый шаг, и даст изменить план.
Приготовьте названия двух задач и краткие наблюдения по первой.

Запуск

1. Понадобится Windows и установленный Python 3.11 или 3.12 с venv и pip.
   Архив уже содержит приложение. Доступ к сети, ключи и подписки не нужны.
2. Выберите в Проводнике «Извлечь все». Откройте распакованную папку
   и запустите START.cmd. Оставьте окно открытым, пока работаете в Studio.
3. Введите две задачи. Для первой укажите выполненные проверки по порядку
   и наблюдение к каждой. Например, «Сверил даты» → «Даты совпали».
   Enter на следующем пустом шаге завершает перечень.
4. Укажите имя или псевдоним подтверждающего. Проверьте сводку и введите
   ПРИНЯТЬ. Источник будет подписан как запись со слов оператора. Оставьте
   финальную строку пустой, если хотите отменить создание этой пары.

В Studio

5. В браузере откроется чат второй задачи. Если окно не открылось,
   скопируйте из консоли адрес после «Вторая задача».
6. Напишите Колосу «Найди порядок проверки из прошлой задачи». В предложении
   откройте источник. Сверьте название первой задачи, шаги, наблюдения
   и автора записи. Ссылка на первую задачу есть также в консоли.
7. Вернитесь в чат второй задачи. Например, для собственной задачи напишите
   «Измени шаг 1: Сверить даты с итоговым отчётом». Чтобы выбрать другого
   проверяющего, отправьте «Проверяющий: Анна». Сверьте итоговый порядок.
   «Перенести в текст задачи» скопирует план в поле сообщения.

Завершение и повторное открытие

Нажмите Ctrl+C в окне START.cmd. При следующем запуске START.cmd откроет
ту же пару. Обе задачи и принятая запись хранятся на вашем компьютере
в %USERPROFILE%\ArachnidPilot2. Черновик изменённого плана живёт во вкладке.
Чтобы сохранить его отдельно, скопируйте итоговый текст до закрытия.
Для новой пары выполните в PowerShell из распакованной папки:

    .\START.cmd new

Созданные ранее проекты остаются в отдельных папках. Записанные шаги
доступны для чтения. Работа с чатом в пилоте обходится без вызовов моделей.

Проверка архива и файлов

Перед распаковкой сравните результат команды с SHA-256 из поставки:

    (Get-FileHash .\Arachnid-Windows-Pilot-2.zip -Algorithm SHA256).Hash

В распакованной папке можно также проверить все файлы командой:

    .\START.cmd verify
