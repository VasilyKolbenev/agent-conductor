Arachnid Studio

Windows · Быстрый старт

1. Установите Python 3.11 или 3.12 с venv и pip. Скачайте Arachnid-Studio-Windows.zip
   и файл Arachnid-Studio-Windows.zip.sha256 со страницы релиза.
   В папке загрузок выполните в PowerShell:

       Get-FileHash -LiteralPath .\Arachnid-Studio-Windows.zip -Algorithm SHA256

   Сравните Hash с первым значением из .zip.sha256. Выберите «Извлечь все».
2. В распакованной папке откройте START.cmd. Окно должно оставаться открытым.
   При первом запуске браузер покажет учебную реконструкцию цикла Codex + Grok.
   Колосс и орбита работают локально. Ключи и подписки для примера не требуются.
3. Выберите Do или спросите Колосса «А что именно Codex исправил?». Справа
   откроются изменения, тесты и вердикт этой попытки. В консоли напечатан
   адрес для открытия вручную. Для завершения нажмите Ctrl+C в этом окне.

Ваши задачи

После закрытия примера введите в PowerShell из распакованной папки:

    .\START.cmd new

Введите названия завершённой и новой задач. Запишите проверки первой задачи
и наблюдение к каждой. Enter на следующем пустом шаге завершает перечень.
Введите имя или псевдоним, сверьте сводку и введите ПРИНЯТЬ.
Чтобы отменить запись, оставьте строку подтверждения пустой.

В чате второй задачи спросите «Найди порядок проверки из прошлой задачи».
Откройте источник и сверьте автора и наблюдения. Вернитесь в чат и напишите,
например, «Измени шаг 1: Сверить даты с итоговым отчётом» и «Проверяющий: Анна».
«Перенести в текст задачи» копирует текст в поле сообщения. Для сохранения на диске
остановите просмотр нажатием Ctrl+C и откройте сохранённую пару командой .\START.cmd edit.
Попросите порядок проверки, внесите правку и нажмите «Сохранить план в задаче».
Следующее открытие пары покажет сохранённые шаги, проверяющего и ссылку на источник.

Следующий START.cmd откроет сохранённую пару. Новые пары хранятся
в %USERPROFILE%\ArachnidStudio. Если вы работали с предыдущей версией,
Studio может открыть прежнюю пару в %USERPROFILE%\ArachnidPilot2.
Вернуться к учебной орбите можно командой .\START.cmd demo.
Проверить все файлы комплекта можно командой .\START.cmd verify.

Чтобы выполнять реальные задачи по своим подпискам, создайте активный проект
и подключите CLI по инструкции:
https://github.com/VasilyKolbenev/agent-conductor/blob/main/docs/first-run-v1.md

Windows · Quick start

Install Python 3.11 or 3.12 with venv and pip. Verify the Windows ZIP against
its .zip.sha256 as shown above, extract it and open START.cmd. The first launch
opens a local reconstruction of a Codex + Grok run. Select Do to inspect the
changes, tests and independent verdict. No provider account is needed to explore.
Press Ctrl+C in the launcher window to close Studio.

For your own tasks, run .\START.cmd new in PowerShell from the extracted folder.
Enter two task titles, the checks and observations from the first, and the name
of the person confirming the record. Type ACCEPT to save. In the second task,
ask Colossus to find the previous checks, open the source and edit the review plan.
To keep the plan on disk, stop the viewer with Ctrl+C and use .\START.cmd edit.
Recall the checks, edit your plan and choose Save plan to task. Reopening the pair
shows the saved steps, reviewer and source. Copy to task text only fills the composer.
START.cmd reopens the latest pair. Use .\START.cmd demo to revisit the example.
For real tasks, connect your own CLI subscriptions in an active project:
https://github.com/VasilyKolbenev/agent-conductor/blob/main/docs/first-run-v1.en.md
